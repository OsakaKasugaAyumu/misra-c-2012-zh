把处理器相关的位运算留在接口背后

client.c 只调用 channel_mask.h 暴露的接口；真正执行哪一种位运算，由 channel_mask.c 的构建选项决定。

阅读对应准则译文自编源码验证记录证据边界

自编 C 示例（非原文）

channel_mask.c下载源码
/* 自编 C 示例（非原文） | One replaceable mask implementation */
#include <limits.h>
#include "channel_mask.h"

#if UINT_MAX != 0xFFFFFFFFU
#error This example needs 32 value bits in unsigned int
#endif
#ifndef USE_X86_MASK
#define USE_X86_MASK 0
#endif
#if USE_X86_MASK && !(defined(__GNUC__) && defined(__x86_64__))
#error The selected backend needs GCC-compatible x86-64 assembly
#endif

unsigned int invert_channels(unsigned int mask)
{
#if USE_X86_MASK
    __asm__("notl %0" : "+r" (mask));
    return mask;
#else
    return ~mask;
#endif
}

#ifndef CHANNEL_MASK_H

/* Return the complementary mask for a bank of 32 channels. */
unsigned int invert_channels(unsigned int mask);

#endif
client.c下载源码
/* 自编 C 示例（非原文） | Client: use the interface, not an instruction */
#include <stdio.h>
#include "channel_mask.h"

int main(void)
{
    unsigned int free_mask = invert_channels(0x00FF00FFU);
    unsigned int all_free = invert_channels(0U);
    printf("free=%08X all-free=%08X\n", free_mask, all_free);
    return ((free_mask == 0xFF00FF00U) &&
            (all_free == 0xFFFFFFFFU)) ? 0 : 1;
}

怎么验证，观察到了什么？

保持调用方不变，只切换 USE_X86_MASK。两次输出的可用位图相同；再从头文件确认调用方无需接触汇编。

复现方式：保存本页各源文件，保持文件名和子目录不变，在它们的共同根目录按顺序执行。记录环境：GCC 13.4.0 / x86_64-pc-cygwin。下列为实际退出码；诊断只摘与实验相关的行。符号 $ 表示命令提示符，不必输入。
