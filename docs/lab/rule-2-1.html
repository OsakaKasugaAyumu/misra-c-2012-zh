实验 20 / 31　·　Rule 2.1

掩码运算之后，哪个分支没有入口？

slot 来自 key 与 3 的按位与。对照代码却用 slot 等于 4 作为返回 99 的条件。

自编源码验证记录证据边界

自编 C 示例（非原文）

demo.c下载源码
/* 自编 C 示例（非原文） | Rule 2.1 */
static unsigned int lane(unsigned int key)
{
    unsigned int slot = key & 3U;
#ifdef COMPARE
    if (slot == 4U) {
        return 99U;
    }
#endif
    return slot;
}
int main(void)
{
    unsigned int i;
    for (i = 0U; i < 16U; ++i) {
        if (lane(i) != (i % 4U)) { return 1; }
    }
    return 0;
}

怎么验证，观察到了什么？

两个程序都通过了 16 个输入。判断分支不可达靠的不是样本数，而是掩码只保留最低两位，结果只能在 0 到 3 之间。

证据边界

这个推理依赖赋值表达式和判断之间没有改写 slot，不能套用于任意看似没走到的分支。
