把容量约定连到代码与测试

这个盒子有 12 个槽。先写两项约定：未满时报告剩余数；达到或超过容量时报零。box.c 的 BOX-01、BOX-02 分别标记它们的实现。

阅读对应准则译文自编源码验证记录证据边界

自编 C 示例（非原文）

box.c下载源码
/* 自编 C 示例（非原文）：由 Codex 为本项目独立编写；不是原书示例，也不是官方合规证明。 */
#include "box.h"

#define BOX_CAPACITY 12U

unsigned int box_free_slots(unsigned int occupied)
{
    if (occupied >= BOX_CAPACITY) { /* BOX-02: full or above capacity */
        return 0U;
    }
    return BOX_CAPACITY - occupied; /* BOX-01: count unused slots */
}

/* 自编 C 示例（非原文）：由 Codex 为本项目独立编写；不是原书示例，也不是官方合规证明。 */
#include <limits.h>
#include <stdio.h>
#include "box.h"

int main(void)
{
    int failures = 0;
    failures += (box_free_slots(0U) != 12U);           /* B01 */
    failures += (box_free_slots(11U) != 1U);           /* B02 */
    failures += (box_free_slots(12U) != 0U);           /* B03 */
    failures += (box_free_slots(13U) != 0U);           /* B04 */
    failures += (box_free_slots(UINT_MAX) != 0U);      /* B05 */
    (void)printf("box checks: %d/5 passed\n", 5 - failures);
    return (failures == 0) ? 0 : 1;
}

怎么验证，观察到了什么？

沿第一条约定检查 B01、B02（占用 0、11）；沿第二条检查 B03–B05（12、13、UINT_MAX）。测试汇总显示五项都命中了预期值。

复现方式：保存本页各源文件，保持文件名和子目录不变，在它们的共同根目录按顺序执行。记录环境：GCC 13.4.0 / x86_64-pc-cygwin。下列为实际退出码；诊断只摘与实验相关的行。符号 $ 表示命令提示符，不必输入。

$ gcc -std=c99 -pedantic-errors -Wall -Wextra -O0 box.c check_box.c -o demo

实际退出码：0 · 符合预期

$ ./demo

标准输出：

证据边界

能核查的是这两项约定、两个实现分支和五个断言的对应关系，不是项目需求已经完整，也不是五个样本穷尽了输入。
