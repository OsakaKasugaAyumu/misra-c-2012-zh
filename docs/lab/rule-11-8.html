实验 80 / 81　·　Rule 11.8

保留所指类型的限定符

区分固定不变的指针和所指类型的限定。通过保留 const volatile 的视图读取，对照一次移除两项限定。

阅读对应准则译文自编源码验证步骤证据边界

自编 C 示例（非原文）

demo.c下载源码
/* 自编 C 示例（非原文） | Rule 11.8 | C99 */
#include <stdio.h>
int main(void)
{
    unsigned int count = 5U;
    unsigned int * const fixed = &count;
    unsigned int *same = fixed;
    const volatile unsigned int *view = same;
#ifdef COMPARE
    unsigned int *plain = (unsigned int *)view;
    (void)plain; /* No access through this pointer. */
#endif
    unsigned int snapshot = *view;
    printf("snapshot=%u\n", snapshot);
    return (snapshot == 5U) ? 0 : 1;
}

怎么验证？

下载 demo.c，在同一目录按组复做。GCC 13.4.0，目标 x86_64-pc-cygwin。指针对照仅预处理或检查语法，不运行对照。

C99 · 正例（3 步）
  1. gcc -std=c99 -pedantic -Wall -Wextra -Wconversion -Wcast-qual -Wcast-function-type -O0 demo.c -o demo.exe

    预期退出码：0；实际退出码：0。

  2. ./demo.exe

    预期退出码：0；实际退出码：0。

  3. gcc -std=c99 -pedantic -Wall -Wextra -Wconversion -Wcast-qual -Wcast-function-type -O0 -E -P demo.c

    预期退出码：0；实际退出码：0。

C99 · 对照（2 步）
  1. gcc -std=c99 -pedantic -Wall -Wextra -Wconversion -Wcast-qual -Wcast-function-type -O0 -DCOMPARE -E -P demo.c

    预期退出码：0；实际退出码：0。

  2. gcc -std=c99 -pedantic -Wall -Wextra -Wconversion -Wcast-qual -Wcast-function-type -O0 -DCOMPARE -fsyntax-only demo.c

    预期退出码：0；实际退出码：0。

实际观察与审查依据

正例输出 snapshot=5。对照语法检查退出 0；未执行对照。 GCC：warning: cast discards 'const volatile' qualifier from pointer target type [-Wcast-qual]。

证据边界

本机能报告丢弃限定符。没有通过去限定指针写入，也没有用一次读取证明优化器、MMIO 或并发访问行为。
