1　愿景

底本定位 PDF 9 ／ 印刷 1

原文译文

MISRA C 指南定义了 C 语言的一个子集。使用这个子集，可以消除或减少犯错的机会。许多安全相关软件开发标准要求或建议使用语言子集；开发任何对完整性或可靠性要求高的应用时，也可以采用这个子集。

除了定义这个子集，本指南还提供：

  • 供 C 程序开发者学习的材料；
  • 供工具开发者参考的材料。

MISRA C 的早期版本以 ISO 于 1990 年给出的 C 语言定义为基础。嵌入式实现现已在不同程度上采纳 ISO 于 1999 年给出的定义，因此我们认为，是时候出版一版纳入 1999 年 ISO 定义的 MISRA C 了。

我们全面审查了上一版指导内容的每一个方面，并在适当之处作了改进。第三版还纳入了根据早期版本使用者的反馈而编写的材料。

第三版的一项重大变化，是将第二版的“底层类型”（underlying type）概念发展为“本质类型”（essential type）。借助新的本质类型概念，我们得以制定一组准则，为 C 语言引入更强的类型约束。

因此，MISRA C 第三版的目标是：

  • 采用 ISO 于 1999 年给出的 C 语言定义，同时保留对较早的 1990 年定义的支持；
  • 修正第二版中任何已知的问题；
  • 增加有充分理由支持的新准则；
  • 改进现有准则的规定及其理由说明；
  • 删除理由不充分的准则；
  • 增加可用静态分析工具处理的准则数量；
  • 指导读者判断各项准则对自动生成代码的适用性。
