前言

乍看之下，MISRA C 指南的这第三次修订似乎令人望而却步。它的篇幅约为上一版的两倍，读者可能会以为准则的数量也翻了一番，而遵守这些准则要花上两倍的功夫。

实际上，准则数量的增幅相对有限，约为 10%。篇幅的其余增量来自指导内容的改进，例如：

  • 更充分地解释了制定准则的理由；
  • 描述更精确；
  • 为大部分准则提供了展示合规与不合规情形的代码示例；
  • 对合规检查和偏离程序给出了更详细的指导；
  • 提供了可用于支持合规声明的检查表。

最后，我想请大家留意本文件的导论部分。这些章节不仅就如何使用 MISRA C 提供了实用指导，而且比以往版本更为简练。我鼓励每一位使用者熟悉这部分材料。

Steve Montgomery，剑桥大学文学硕士（MA (Cantab)）、博士（PhD）
MISRA C 工作组主席
