H.2　关键的未指定行为

原文译文

表中各栏的含义如下：

  • C90 编号是该未指定行为在 C90 标准附录 G 中的编号。若该行为在标准正文中有所提及、却未列入附录 G，本栏以 * 表示。
  • C99 编号是该未指定行为在 C99 标准附录 J 中的编号。
  • “是否关键”一栏标为“是”或“否”，取决于依赖这种行为是否很可能使程序的运行偏离预期。
  • “准则”栏列出遵守后即可避免该未指定行为的 MISRA C 准则。
  • “备注”栏给出对该行为的补充说明，包括即使不能完全避免该行为、也可能有所帮助的规则。

如果某项未指定行为被标为关键，但“准则”栏中没有条目，那么程序依赖该行为就违反 Rule 1.3。

注：这里假设以其他语言编写并与程序链接的任何代码都不会直接或间接依赖未指定行为。例如，汇编语言函数可能试图访问形参，尽管形参的布局是未指定的。
