原文译文

本附录列出 Rule 1.3 所提及的未定义行为和关键的未指定行为。

H.1　未定义行为

表中各栏的含义如下：

  • C90 编号是该未定义行为在 C90 标准附录 G 中的编号。若该行为在标准正文中有所提及、却未列入附录 G，本栏以 * 表示。
  • C99 编号是该未定义行为在 C99 标准附录 J 中的编号。
  • “是否可判定”一栏标为“是”或“否”，表示检出这类行为的实例在一般情形下是否为可判定问题。
  • “准则”栏列出遵守后即可避免该未定义行为的 MISRA C 准则。
  • “备注”栏给出对该行为的补充说明，包括即使不能完全避免该行为、也可能有所帮助的规则。

如果某项未定义行为的“准则”栏中没有条目，那么该行为只要在程序中出现，就违反 Rule 1.3。

注：这里假设以其他语言编写并与程序链接的任何代码都不会直接或间接引入未定义行为。例如，汇编语言模块可能定义了存储重叠的对象；从 C 代码访问这些对象会导致未定义行为，但仅从 C 源代码中可能看不出来。
