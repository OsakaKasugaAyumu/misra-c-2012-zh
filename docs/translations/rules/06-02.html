Rule 6.2 · 具名单比特位域的符号性

底本定位 §8.6 · PDF 67／印刷 59

原文译文

Rule 6.2　具名的单比特位域不得具有有符号类型。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

根据 C99 标准 §6.2.6.2，有符号的单比特位域有一个符号位，没有数值位。在任何整数表示中，零个数值位都不足以指定一个有意义的值。

因此，有符号的单比特位域不大可能表现出有用的行为；出现这样的位域，很可能表明程序员有所误解。

尽管 C90 标准对于类型的表示没有给出同样详细的规定，但上述针对 C99 的考虑也同样适用。

注： 本规则不适用于未命名的位域，因为其值不可访问。
