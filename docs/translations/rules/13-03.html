Rule 13.3 · 自增、自减与其他潜在副作用

底本定位 规则 PDF／印刷 119–120／111–112。

原文译文

Rule 13.3　完整表达式中如含有自增（++）或自减（--）运算符，除该自增或自减运算符引起的副作用外，不应再有其他潜在副作用。

C90 [未指定 7、8；未定义 18]；C99 [未指定 15；未定义 32]

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

就本规则而言，函数调用视为副作用。对完整表达式的每个子表达式，本规则均按会对其求值来处理，即使 C 标准规定不对它求值也是如此。

理由

不建议将自增、自减操作与其他运算符结合使用，原因如下：

  • 这样做可能显著损害代码的可读性；
  • 它会向一条语句引入额外的副作用，可能导致未定义行为（由 Rule 13.2 涵盖）。

单独使用这些操作，不与任何其他运算符组合，意图更清楚。

原书示例

表达式：

u8a = u8b++

不符合本规则。下面这条不符合本规则的表达式语句：

u8a = ++u8b + u8c--;

写成如下序列更清楚：

++u8b;
u8a = u8b + u8c;
u8c--;

以下各例均符合本规则，因为每个表达式中唯一的副作用都是由自增或自减运算符引起的。

x++;
a[ i ]++;
b.x++;
c->x++;
++( *p );
*p++;
( *p )++;

以下各例均不符合本规则，因为它们除了自增或自减运算符外还含有函数调用：

if ( ( f ( ) + --u8a ) == 0u )
{
}

g ( u8b++ );

以下各例也都不符合本规则，即使含有自增、自减或其他副作用的子表达式并未求值：

u8a = ( 1u == 1u ) ? 0u : u8b++;

if ( u8a++ == ( ( 1u == 1u ) ? 0u : f ( ) ) )
{
}
