Rule 17.6 · 不在数组形参的方括号内写 static

底本定位 PDF／印刷 148–149／140–141。

原文译文

Rule 17.6　数组形参的声明不得在方括号 [ ] 之间包含关键字 static。

C99 [未定义 71]

类别
强制（Mandatory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

理由

C99 语言标准提供了一种机制，使程序员可以告知编译器：数组形参所指的数组至少含有指定数量的元素。在某些类型的处理器上，有些编译器可以利用这项信息生成更高效的代码。

如果程序员作出的保证未兑现，即元素数少于指定的最小值，行为就未定义。

典型嵌入式应用所使用的处理器不大可能具备利用这项额外信息所需的机制。程序未能满足最低元素数保证的风险，超过了潜在的性能收益。

原书示例

对这项 C99 特性的任何使用都不符合本条。下例展示了使用它时可能产生的一些未定义行为。

/* Non-compliant - uses static in array declarator */
uint16_t total ( uint16_t n, uint16_t a[ static 20 ] )
{
  uint16_t i;

  uint16_t sum = 0U;

  /* Undefined behaviour if a has fewer than 20 elements */
  for ( i = 0U; i < n; ++i )
  {
    sum = sum + a[ i ];
  }

  return sum;
}

extern uint16_t v1[ 10 ];
extern uint16_t v2[ 20 ];

void g ( void )
{
  uint16_t x;

  x = total ( 10U, v1 );   /* Undefined - v1 has 10 elements but needs
                            *             at least 20                   */
  x = total ( 20U, v2 );   /* Defined but non-compliant                 */
}

原书代码注释中译（依次）： （1）不合规：在数组声明符中使用 static。 （2）如果 a 的元素少于 20 个，则行为未定义。 （3）未定义：v1 只有 10 个元素，但至少需要 20 个。 （4）行为有定义，但不合规。
