Rule 13.5 · 短路右侧的持久副作用

底本定位 规则 PDF／印刷 121–122／113–114。

原文译文

Rule 13.5　逻辑与（&&）或逻辑或（||）运算符的右操作数不得含有持久副作用。

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

是否对 && 和 || 的右操作数求值，取决于左操作数的值。如果右操作数含有副作用，这些副作用可能发生，也可能不发生，这或许与程序员的预期相反。

如果对右操作数求值所产生的副作用，在程序中该表达式所在的位置并不持久，那么是否对右操作数求值就无关紧要。

“持久副作用”这一术语的定义见附录 J。

原书示例

uint16_t f ( uint16_t y )
{
  /* These side effects are not persistent as seen by the caller */
  uint16_t temp = y;

  temp = y + 0x8080U;

  return temp;
}

uint16_t h ( uint16_t y )
{
  static uint16_t temp = 0;

  /* This side effect is persistent                              */
  temp = y + temp;

  return temp;
}

void g ( void )
{
  /* Compliant - f ( ) has no persistent side effects            */
  if ( ishigh && ( a == f ( x ) ) )
  {
  }

  /* Non-compliant - h ( ) has a persistent side effect          */
  if ( ishigh && ( a == h ( x ) ) )
  {
  }
}

volatile uint16_t v;
         uint16_t x;

/* Non-compliant - access to volatile v is persistent */
if ( ( x == 0u ) || ( v == 1u ) )
{
}

/* Non-compliant if fp points to a function with persistent side effects */
( fp != NULL ) && ( *fp ) ( 0 );

原书代码注释中译（按出现顺序）： 在调用者看来，f 内的副作用并不持久；h 对静态对象的修改则是持久的。右侧调用 f 的条件符合，调用 h 的不符合。访问 volatile 对象 v 是持久的，故该逻辑或不符合。若 fp 指向具有持久副作用的函数，最后的间接调用也不符合。
