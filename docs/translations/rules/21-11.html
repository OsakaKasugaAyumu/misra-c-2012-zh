Rule 21.11 · 从头文件和调用点辨认泛型宏

底本定位 PDF／印刷 179／171。

原文译文

Rule 21.11　不得使用标准头文件 <tgmath.h>。

C99 [未定义 184、185]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

进一步说明

不得使用规定由 <tgmath.h> 提供的任何设施。

理由

使用 <tgmath.h> 的设施可能导致未定义行为。

原书示例

#include <tgmath.h>

float f1, f2;

void f ( void )
{
  f1 = sqrt ( f2 );    /* Non-compliant - generic sqrt used      */
}

#include <math.h>

float f1, f2;

void f ( void )
{
  f1 = sqrtf ( f2 );   /* Compliant - float version of sqrt used */
}

原书代码注释中译（依次）： （1）不合规：使用了泛型 sqrt。 （2）合规：使用了 sqrt 的 float 版本。
