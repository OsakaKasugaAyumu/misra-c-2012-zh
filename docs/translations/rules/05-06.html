Rule 5.6 · typedef 名的唯一性

底本定位 §8.5 · PDF 62／印刷 54

原文译文

Rule 5.6　typedef 名必须是唯一的标识符。

类别
必需（Required）
分析
可判定（Decidable），系统（System）
适用标准
C90、C99

进一步说明

typedef 名在所有名字空间和翻译单元中必须唯一。只有当类型定义写在一个头文件中，而该头文件又被多个源文件包含时，本规则才允许同一 typedef 名有多处声明。

理由

把一个 typedef 名再次用作另一个 typedef 名，或用作函数、对象或枚举常量的名字，可能使开发者产生混淆。

例外

typedef 名可以与同该 typedef 相关联的结构、联合或枚举的标记名相同。

原书示例

void func ( void )
{
  {
    typedef unsigned char u8_t;
  }
  {
    typedef unsigned char u8_t;    /* Non-compliant - reuse */
  }
}

typedef float mass;

void func1 ( void )
{
  float32_t mass = 0.0f;           /* Non-compliant - reuse */
}

typedef struct list
{
  struct list *next;
  uint16_t     element;
} list;                            /* Compliant - exception */

typedef struct
{
  struct chain
  {
    struct chain *list;
    uint16_t      element;
  } s1;
  uint16_t length;
} chain;                           /* Non-compliant - tag "chain" not
                                    * associated with typedef            */

另见

Rule 5.7。

原书代码注释中译（按出现顺序）　第二次定义 u8_t 以及把 mass 用作对象名都是重复使用，不符合。list 按例外符合；chain 的标记并未与该 typedef 相关联，不符合。
