Rule 13.6 · sizeof 与潜在副作用

底本定位 规则 PDF／印刷 122–123／114–115。

原文译文

Rule 13.6　sizeof 运算符的操作数不得含有任何具有潜在副作用的表达式。

C99 [未指定 21]

类别
强制（Mandatory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

出现在 sizeof 操作数中的表达式通常不求值。本规则强制要求：对其中任一表达式求值都不得产生副作用，无论实际上是否对它求值。

就本规则而言，函数调用视为副作用。

理由

sizeof 的操作数可以是表达式，也可以指定一种类型。如果操作数中包含表达式，程序员可能错误地期待它会被求值，而实际上大多数情况下并不会求值。

C90 标准规定，操作数中出现的表达式不在运行时求值。

在 C99 中，操作数中出现的表达式通常不在运行时求值。不过，如果操作数包含变长数组类型，则在有必要时会对数组大小表达式求值。如果无需求该大小表达式的值即可确定结果，则是否对它求值是未指定的。

例外

允许使用 sizeof ( V ) 形式的表达式，其中 V 是具有 volatile 限定类型、且不是变长数组的左值。

原书示例

volatile int32_t i;
         int32_t j;
         size_t  s;

s = sizeof ( j );         /* Compliant             */
s = sizeof ( j++ );       /* Non-compliant         */
s = sizeof ( i );         /* Compliant - exception */
s = sizeof ( int32_t );   /* Compliant             */

下例最后一个 sizeof 表达式展示了变长数组的大小表达式如何可能不影响类型的大小。操作数的类型为“由 n 个函数指针构成的数组；所指函数有一个形参，其类型写作由 v 个 int32_t 构成的数组”。由于操作数具有变长数组类型，它会被求值。然而，这 n 个函数指针所占的大小不受所指函数形参列表的影响。因此，是否对具有 volatile 限定的对象 v 求值都可能，其副作用也可能发生或不发生。

volatile uint32_t v;

void f ( int32_t n )
{
  size_t s;

  s = sizeof ( int32_t[ n ] );                         /* Compliant     */
  s = sizeof ( int32_t[ n++ ] );                       /* Non-compliant */
  s = sizeof ( void ( *[ n ] ) ( int32_t a[ v ] ) );   /* Non-compliant */
}

另见

Rule 18.8。

原书代码注释中译（按出现顺序）： sizeof ( j ) 符合；以 j++ 作操作数不符合；sizeof ( i ) 按例外符合；以 int32_t 作操作数符合。三个涉及变长数组的例子依次标为符合、不符合、不符合。
