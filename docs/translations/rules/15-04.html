Rule 15.4 · 逐层计数循环的提前出口

底本定位 PDF／印刷 133–134／125–126。

原文译文

Rule 15.4　对任一迭代语句，用于终止该迭代的 break 或 goto 语句合计不应超过一条。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

限制循环的出口数，有助于降低阅读代码时控制流的复杂程度。当确需提前终止循环时，使用一条 break 或 goto 可以建立一条额外的退出路径。

原书示例

下面嵌套的两个循环都合规，因为每一层都只使用一条 break 提前终止本层循环。

for ( x = 0; x < LIMIT; ++x )
{
  if ( ExitNow ( x ) )
  {
    break;
  }

  for ( y = 0; y < x; ++y )
  {
    if ( ExitNow ( LIMIT - y ) )
    {
      break;
    }
  }
}

下面的循环不合规，因为用于提前终止循环的 break 和 goto 不止一条。

for ( x = 0; x < LIMIT; ++x )
{
  if ( BreakNow ( x ) )
  {
    break;
  }
  else if ( GotoNow ( x ) )
  {
    goto EXIT;
  }
  else
  {
    KeepGoing ( x );
  }
}

EXIT:
  ;

下例中，内层 while 合规，因为只有一条 goto 能使其提前终止。但外层 while 不合规，因为它既可能由 break 提前终止，也可能由内层 while 中的 goto 提前终止。

while ( x != 0u )
{
  x = calc_new_x ( );

  if ( x == 1u )
  {
    break;
  }

  while ( y != 0u )
  {
    y = calc_new_y ( );

    if ( y == 1u )
    {
      goto L1;
    }
  }
}

L1:
z = x + y;
