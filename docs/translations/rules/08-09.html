Rule 8.9 · 仅在一个函数中出现的对象名

底本定位 §8.8 · PDF／印刷 79–80／71–72

原文译文

Rule 8.9　如果对象的标识符只出现在一个函数中，则该对象应当定义在块作用域内。

类别
建议（Advisory）
分析
可判定（Decidable），系统（System）
适用标准
C90、C99

理由

在块作用域内定义对象，可降低被无意访问的可能性，并明确表达不应从别处访问它的意图。

在一个函数内，将对象定义在最外层块还是最内层块，主要是风格问题。

确实存在可能无法遵守本规则的情况。例如，在块作用域声明的、具有静态存储期的对象不能从块外直接访问。因此，如果不通过间接访问该对象，就无法设置单元测试用例的初始状态并检查其结果。在这类情况下，有些项目可能宁愿不应用本规则。

原书示例

在这个符合本规则的示例中，i 在块作用域声明，因为它是循环计数器。同一文件中的其他函数不需要把同一对象用于任何其他目的。

void func ( void )
{
  int32_t i;

  for ( i = 0; i < N; ++i )
  {
  }
}

在这个符合本规则的示例中，函数 count 记录自己被调用的次数并返回该次数。没有其他函数需要知道 count 的实现细节，所以调用计数器定义在块作用域内。

uint32_t count ( void )
{
  static uint32_t call_count = 0;

  ++call_count;
  return call_count;
}
