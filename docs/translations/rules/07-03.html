Rule 7.3 · 字面量后缀中的小写 l

底本定位 §8.7 · PDF 69–70／印刷 61–62

原文译文

Rule 7.3　字面量后缀中不得使用小写字母 l。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

声明字面量时使用大写后缀 L，可以消除 1（数字一）和 l（小写字母 L）之间可能产生的歧义。

原书示例

注： 含有 long long 后缀的示例只适用于 C99。

const int64_t    a = 0L;
const int64_t    b = 0l;     /* Non-compliant */
const uint64_t   c = 0Lu;
const uint64_t   d = 0lU;    /* Non-compliant */
const uint64_t   e = 0ULL;
const uint64_t   f = 0Ull;   /* Non-compliant */
const int128_t   g = 0LL;
const int128_t   h = 0ll;    /* Non-compliant */
const float128_t m = 1.2L;
const float128_t n = 2.4l;   /* Non-compliant */

原书代码注释中译（按出现顺序）　原注在 b、d、f、h、n 旁标出了“不符合”。
