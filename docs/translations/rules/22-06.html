Rule 22.6 · 关闭之后只记录独立的资源编号

底本定位 PDF／印刷 185／177。

原文译文

Rule 22.6　关联的流一经关闭，就不得使用指向该 FILE 的指针值。

C99 [未定义 140]

类别
强制（Mandatory）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

C 标准指出，对流进行关闭操作后，相应 FILE 指针的值是不确定的（indeterminate）。

原书示例

#include <stdio.h>

void fn ( void )
{
  FILE *fp;
  void *p;

  fp = fopen ( "tmp", "w" );

  if ( fp == NULL )
  {
    error_action ( );
  }

  fclose ( fp );

  fprintf ( fp, "?" );   /* Non-compliant */
  p = fp;                /* Non-compliant */
}

原书代码注释中译（依次）： （1）不合规。 （2）不合规。

另见

Dir 4.13、Rule 21.6。
