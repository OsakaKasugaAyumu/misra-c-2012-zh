Rule 4.1 · 八进制与十六进制转义序列

底本定位 §8.4 · PDF 54–55／印刷 46–47

原文译文

8.4　字符集与词法约定

Rule 4.1　八进制和十六进制转义序列必须有明确的终止位置。

C90 [Implementation 11]，C99 [Implementation J.3.4(7, 8)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

八进制或十六进制转义序列必须以下列方式之一终止：

  • 另一个转义序列开始；或者
  • 到达字符常量的末尾，或字符串字面量的末尾。

理由

如果八进制或十六进制转义序列之后紧跟着其他字符，就有可能引起混淆。例如，字符常量 '\x1f' 由一个字符组成，而字符常量 '\x1g' 由两个字符组成，即 '\x1' 和 'g'。多字符常量如何用整数表示，是实现定义的。

如果字符常量或字符串字面量中的每一个八进制或十六进制转义序列都有明确的终止位置，就能减少这种混淆。

原书示例

本例中，s1、s2 和 s3 所指的每一个字符串都等价于 "Ag"。

const char *s1 = "\x41g";    /* Non-compliant                            */
const char *s2 = "\x41" "g"; /* Compliant - terminated by end of literal */
const char *s3 = "\x41\x67"; /* Compliant - terminated by another escape */

int c1 = '\141t';            /* Non-compliant                            */
int c2 = '\141\t';           /* Compliant - terminated by another escape */

原书代码注释中译（依次）： s1 不合规；s2 合规，以该字面量的末尾终止；s3 合规，由另一个转义序列终止。c1 不合规；c2 合规，由另一个转义序列终止。

另见

C90：第 6.1.3.4 节；C99：第 6.4.4.4 节。
