Rule 5.4 · 宏标识符的区分

底本定位 §8.5 · PDF 59–60／印刷 51–52

原文译文

Rule 5.4　不同的宏标识符必须可区分。

C90 [未定义 7]，C99 [未指定 7；未定义 28]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则要求，在定义一个宏时，它的名字必须能与下列名字区分开：

  • 当前已定义的其他宏的名字；以及
  • 这些宏的形参名。

本规则还要求，同一个宏的各个形参名必须彼此可区分，但并不要求两个不同宏的形参名彼此可区分。

何谓“可区分”，取决于实现以及所使用的 C 语言版本：

  • C90 的最低要求是宏标识符的前 31 个字符有效；
  • C99 的最低要求是宏标识符的前 63 个字符有效。

实际上，实现可能提供更高的限度。本规则要求宏标识符在实现规定的限度内可区分。

理由

如果两个宏标识符只在非有效字符上有差别，行为就是未定义的。由于宏形参只在其所属宏的展开过程中起作用，一个宏的形参不会与另一个宏的形参相混淆。

如果需要考虑可移植性，审慎的做法是按 C 标准规定的最低限度应用本规则。

宏标识符过长可能妨碍阅读代码。许多自动代码生成系统都会产生很长的宏标识符，但仍有充分理由把宏标识符长度控制在远低于上述限度的范围内。

注： 在 C99 中，如果宏名含有一个扩展源字符，而该字符又没有对应的通用字符，C 标准未规定它占多少个字符。

原书示例

在下面的示例中，这里的实现支持宏标识符有 31 个有效字符，区分大小写。

/*       1234567890123456789012345678901*********             Characters */
#define  engine_exhaust_gas_temperature_raw     egt_r
#define  engine_exhaust_gas_temperature_scaled  egt_s   /* Non-compliant */

/*       1234567890123456789012345678901*********             Characters */
#define  engine_exhaust_gas_temp_raw            egt_r
#define  engine_exhaust_gas_temp_scaled         egt_s   /* Compliant     */
