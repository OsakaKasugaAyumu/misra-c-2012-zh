Rule 16.5 · 将 default 放在首位或末位

底本定位 PDF／印刷 142／134。

原文译文

Rule 16.5　default 标号必须是 switch 语句中的第一个或最后一个 switch 标号。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

这条规则使人容易在 switch 语句中找到 default 标号。

原书示例

switch ( x )
{
  default:   /* Compliant - default is the first label                */
  case 0:
    ++x;
    break;
  case 1:
  case 2:
    break;
}

switch ( x )
{
  case 0:
    ++x;
    break;
  default:   /* Non-compliant - default is mixed with the case labels */
    x = 0;
    break;
  case 1:
  case 2:
    break;
}

switch ( x )
{
  case 0:
    ++x;
    break;
  case 1:
  case 2:
    break;
  default:   /* Compliant - default is the final label                */
    x = 0;
    break;
}

原书代码注释中译（依次）： （1）合规：default 是第一个标号。 （2）不合规：default 夹在 case 标号之间。 （3）合规：default 是最后一个标号。

另见

Rule 15.7、Rule 16.1。
