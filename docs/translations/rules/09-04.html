Rule 9.4 · 同一元素的重复初始化

底本定位 §8.9 · PDF／印刷 87–88／79–80

原文译文

Rule 9.4　对象的同一个元素不得被初始化多次。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

进一步说明

本规则同时适用于对象和子对象的初始化器。

C99 提供的指定初始化器允许在初始化列表中指名聚合（结构体或数组）或联合中的组成部分，并允许通过指定相应的数组下标或结构体成员名，以任意顺序初始化对象的各个元素（没有给出初始值的元素采用未初始化对象的默认值）。

理由

使用指定初始化器时需要小心，因为可能无意中重复初始化某个元素，从而覆盖先前对该元素的初始化。C99 标准未规定被覆盖的初始化器中的副作用是否发生，尽管附录 J 没有列出这一点。

为允许使用稀疏的数组和结构体，只初始化应用所需要的那些元素是可以接受的。

原书示例

数组初始化：

/*
 * Required behaviour using positional initialization
 * Compliant - a1 is -5, -4, -3, -2, -1
 */
int16_t a1[ 5 ] = { -5, -4, -3, -2, -1 };

/*
 * Similar behaviour using designated initializers
 * Compliant - a2 is -5, -4, -3, -2, -1
 */
int16_t a2[ 5 ] = { [ 0 ] = -5, [ 1 ] = -4, [ 2 ] = -3,
                    [ 3 ] = -2, [ 4 ] = -1              };

/*
 * Repeated designated initializer element values overwrite earlier ones
 * Non-compliant - a3 is -5, -4, -2, 0, -1
 */
int16_t a3[ 5 ] = { [ 0 ] = -5, [ 1 ] = -4, [ 2 ] = -3,
                    [ 2 ] = -2, [ 4 ] = -1              };

在下面这个不符合本规则的示例中，副作用是否发生是未指定的：

uint16_t *p;

void f ( void )
{
  uint16_t a[ 2 ] = { [ 0 ] = *p++, [ 0 ] = 1 };
}

结构体初始化：

struct mystruct
{
  int32_t a;
  int32_t b;
  int32_t c;
  int32_t d;
};

/*
 * Required behaviour using positional initialization
 * Compliant - s1 is 100, -1, 42, 999
 */
struct mystruct s1 = { 100, -1, 42, 999 };

/*
 * Similar behaviour using designated initializers
 * Compliant - s2 is 100, -1, 42, 999
 */
struct mystruct s2 = { .a = 100, .b = -1, .c = 42, .d = 999 };

/*
 * Repeated designated initializer element values overwrite earlier ones
 * Non-compliant - s3 is 42, -1, 0, 999
 */
struct mystruct s3 = { .a = 100, .b = -1, .a = 42, .d = 999 };

原书代码注释中译（按出现顺序）： a1 按位置给出所需行为，a2 用指定项实现相似行为；两者符合，值均为 −5、−4、−3、−2、−1。a3 的重复指定项覆盖先前的值，不符合，结果为 −5、−4、−2、0、−1。s1 按位置初始化，s2 用指定项，均符合并得到 100、−1、42、999；s3 的重复指定项覆盖先前的值，不符合，结果为 42、−1、0、999。
