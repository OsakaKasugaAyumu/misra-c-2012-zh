Rule 11.8 · 保留所指类型的限定符

底本定位 规则 PDF／印刷 108–109／100–101。

原文译文

Rule 11.8　强制转换不得移除指针所指类型上的任何 const 或 volatile 限定。

C90 [未定义 12、39、40]；C99 [未定义 30、61、62]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

用强制转换移除所寻址类型的限定，违背了类型限定的原则。

注： 此处所说的限定，与可能施加在指针本身上的限定不同。

移除所寻址对象的限定符可能带来以下问题：

  • 移除 const 可能绕过对象的只读状态，导致对象被修改；
  • 移除 const 可能导致访问对象时发生异常；
  • 移除 volatile 可能导致对对象的访问被优化掉。

注： 移除 C99 的 restrict 类型限定符不会造成此类危害。

原书示例

         uint16_t          x;
         uint16_t * const  cpi = &x;   /* const pointer               */
         uint16_t * const *pcpi;       /* pointer to const pointer    */
         uint16_t *       *ppi;
   const uint16_t         *pci;        /* pointer to const            */
volatile uint16_t         *pvi;        /* pointer to volatile         */
         uint16_t         *pi;

pi = cpi;                              /* Compliant - no conversion
                                                   no cast required   */
pi  = (uint16_t *)pci;                 /* Non-compliant               */
pi  = (uint16_t *)pvi;                 /* Non-compliant               */
ppi = (uint16_t * *)pcpi;              /* Non-compliant               */

另见

Rule 11.3。

原书代码注释中译（按出现顺序）： cpi 是 const 指针；pcpi 指向 const 指针；pci 指向 const 对象；pvi 指向 volatile 对象。首个赋值符合，无转换、无需强转；其余三项均不符合。
