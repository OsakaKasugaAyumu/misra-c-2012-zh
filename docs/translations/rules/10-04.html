Rule 10.4 · 通常算术转换的两侧

底本定位 规则 PDF／印刷 95–96／87–88。

原文译文

Rule 10.4　对于实施通常算术转换的运算符，两个操作数必须具有相同的本质类型类别。

C90 [实现定义 21]；C99 [实现定义 3.6(4)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则适用于通常算术转换所述的运算符（见 C90 §6.2.1.5、C99 §6.3.1.8）。这包括除移位、逻辑 &&、逻辑 || 和逗号运算符以外的所有二元运算符。此外，本规则也涵盖三元运算符的第二、第三操作数。

注： 自增和自减运算符不在本规则范围内。

理由

C 语言给程序员很大自由，允许不同算术类型之间自动转换。然而，使用这些隐式转换可能产生意外结果，可能损失数值、符号或精度。有关 C 类型系统的问题，附录 C 有更详细的说明。

MISRA 本质类型模型实施更强的类型约束，从而可以把隐式转换限制在应当能产生开发者预期结果的情形。

例外

为允许一种常见的字符处理方式，可使用下列写法：

  1. 二元 + 和 += 运算符的一个操作数可以是本质字符型，另一个可以是本质有符号型或本质无符号型；
  2. 二元 - 和 -= 运算符可以使用本质字符型左操作数，以及本质有符号型或本质无符号型右操作数。

原书示例

enum enuma { A1, A2, A3 } ena;
enum enumb { B1, B2, B3 } enb;

以下写法符合本规则，因为操作数具有相同的本质类型类别：

ena > A1
u8a + u16b

以下写法根据例外 1 符合本规则：

cha += u8a

以下写法不符合本规则，同时也违反 Rule 10.3：

s8a += u8a   /* signed and unsigned         */

以下写法不符合本规则：

u8b + 2      /* unsigned and signed         */
enb > A1     /* enum<enumb> and enum<enuma> */
ena == enb   /* enum<enuma> and enum<enumb> */
u8a += cha   /* unsigned and char           */

另见

Rule 10.3、Rule 10.7。

原书代码注释中译（按出现顺序）： s8a += u8a 混合有符号和无符号。最后四式依次混合无符号和有符号、enum 和 enum、enum 和 enum、无符号和字符。
