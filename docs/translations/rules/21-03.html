Rule 21.3 · 从别名追到分配和释放接口

底本定位 PDF／印刷 175／167。

原文译文

Rule 21.3　不得使用 <stdlib.h> 的内存分配和释放函数。

C90 [未指定 19；未定义 9、91、92；实现定义 69]

C99 [未指定 39、40；未定义 8、9、168–171；实现定义 J.3.12(35)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

不得使用标识符 calloc、malloc、realloc、free，也不得展开与其中任何一个同名的宏。

理由

使用标准库提供的动态内存分配和释放例程，可能导致未定义行为，例如：

  • 释放并非动态分配的内存；
  • 以任何方式使用指向已释放内存的指针；
  • 在向已分配内存存入值之前就访问它。

注： 本规则是 Dir 4.12 的一种具体情形。

另见

Dir 4.12、Rule 18.7、Rule 22.1、Rule 22.2。
