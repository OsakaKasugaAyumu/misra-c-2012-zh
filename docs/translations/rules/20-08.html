Rule 20.8 · 分清零一、非零与未求值

底本定位 PDF／印刷 168–169／160–161。

原文译文

Rule 20.8　#if 或 #elif 预处理指令的控制表达式必须求得 0 或 1。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则不适用于预处理指令中未被求值的控制表达式。如果控制表达式位于正被排除的代码中，而且不能影响代码是否被排除，就不会对它求值。

理由

强类型要求条件包含预处理指令的控制表达式具有布尔值。

原书示例

#define FALSE 0
#define TRUE  1

#if FALSE           /* Compliant                              */
#endif

#if 10              /* Non-compliant                          */
#endif

原书代码注释中译（依次）： （1）合规。 （2）不合规。

#if ! defined ( X ) /* Compliant                              */
#endif

原书代码注释中译（依次）： （1）合规。

#if A > B           /* Compliant assuming A and B are numeric */
#endif

原书代码注释中译（依次）： （1）假定 A 和 B 是数值，则合规。

另见

Rule 14.4。
