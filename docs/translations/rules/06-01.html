Rule 6.1 · 位域的声明类型

底本定位 §8.6 · PDF 66–67／印刷 58–59

原文译文

8.6　类型

Rule 6.1　位域只能用适当的类型声明。

C90 [未定义 38；实现定义 29]，C99 [实现定义 J.3.9(1, 2)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

适当的位域类型如下：

  • C90：unsigned int 或 signed int；
  • C99：以下类型之一：
    • unsigned int 或 signed int；
    • 实现允许的、显式指定为有符号或无符号的其他整数类型；
    • _Bool。

注： 允许用 typedef 名指代适当的类型。

理由

使用 int 的结果由实现定义，因为 int 类型的位域既可能有符号，也可能无符号。

在 C90 中，不允许用 enum、short、char 或上述允许类型之外的任何其他类型声明位域，因为其行为未定义。

在 C99 中，实现可以定义还允许在位域声明中使用哪些其他整数类型。

原书示例

下面的示例适用于 C90，也适用于不提供任何额外位域类型的 C99 实现。它假定 int 类型为 16 位。

typedef unsigned int UINT_16;

struct s {
   unsigned int b1:2;   /* Compliant                                    */
   int          b2:2;   /* Non-compliant - plain int not permitted      */
   UINT_16      b3:2;   /* Compliant - typedef designating unsigned int */
   signed long  b4:2;   /* Non-compliant even if long and int are the
                         * same size                                    */
};

原书代码注释中译（按出现顺序）　b1 符合；b2 是未显式标明符号性的 int，不符合；b3 是指代 unsigned int 的 typedef，符合；在例中给定的实现前提下，b4 不符合，即使 long 与 int 一样宽也不例外。
