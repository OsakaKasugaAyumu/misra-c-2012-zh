Rule 16.6 · 按子句而非标号计数

底本定位 PDF／印刷 143／135。

原文译文

Rule 16.6　每条 switch 语句都必须至少含有两个 switch 子句。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

只有一条路径的 switch 是多余的，而且可能表明存在编程错误。

原书示例

switch ( x )
{
  default:   /* Non-compliant - switch is redundant */
    x = 0;
    break;
}

switch ( y )
{
  case 1:
  default:   /* Non-compliant - switch is redundant */
    y = 0;
    break;
}

switch ( z )
{
  case 1:
    z = 2;
    break;
  default:   /* Compliant                           */
    z = 0;
    break;
}

原书代码注释中译（依次）： （1）不合规：该 switch 多余。 （2）不合规：该 switch 多余。 （3）合规。
