Rule 20.2 · 区分头文件名的定界符与内部字符

底本定位 PDF／印刷 164／156。

原文译文

Rule 20.2　头文件名中不得出现字符 '、"、\，也不得出现字符序列 /* 或 //。

C90 [未定义 14]；C99 [未定义 31]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

以下情况的行为未定义：

  • 在头文件名预处理记号的 < 与 > 定界符之间使用了字符 '、"、\，或字符序列 /*、//；
  • 在头文件名预处理记号的一对 " 定界符之间使用了字符 '、\，或字符序列 /*、//。

注： 虽然使用字符 \ 会导致未定义行为，但许多实现接受以字符 / 代替它。

原书示例

#include "fi'le.h"   /* Non-compliant */

原书代码注释中译（依次）： （1）不合规。
