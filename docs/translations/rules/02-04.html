Rule 2.4 · 未使用的标记声明

底本定位 §8.2 · PDF 51／印刷 43

原文译文

Rule 2.4　项目中不应含有未使用的标记声明。

类别
建议（Advisory）
分析
可判定（Decidable），系统（System）
适用标准
C90、C99

理由

如果一个标记已声明却未使用，审查人员就难以判断该标记是多余的，还是由于疏忽才没有用上。

原书示例

在下例中，标记 state 未被使用；这条声明本可以不写这个标记。

void unusedtag ( void )
{
  enum state { S_init, S_run, S_sleep };   /* Non-compliant */
}

原书代码注释中译： 含有该标记的声明不合规。

在下例中，标记 record_t 仅出现在定义 record1_t 的 typedef 中；本翻译单元其余地方凡是需要这个类型，都使用 record1_t。省略标记就能把这个 typedef 写成合规的形式，见 record2_t 的定义。

typedef struct record_t                    /* Non-compliant */
{
  uint16_t  key;
  uint16_t  val;
} record1_t;

typedef struct                             /* Compliant     */
{
  uint16_t  key;
  uint16_t  val;
} record2_t;

原书代码注释中译： record1_t 的写法不合规；record2_t 的写法合规。
