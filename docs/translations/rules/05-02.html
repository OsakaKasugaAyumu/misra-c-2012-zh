Rule 5.2 · 同一作用域和名字空间中的标识符

底本定位 §8.5 · PDF 57–58／印刷 49–50

原文译文

Rule 5.2　在同一作用域和同一名字空间内声明的标识符必须可区分。

C90 [未定义 7]，C99 [未定义 28]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

如果两个标识符都是外部标识符，则本规则不适用，因为这种情况由 Rule 5.1 涵盖。

如果其中任意一个是宏标识符，本规则也不适用，因为这种情况由 Rule 5.4 和 Rule 5.5 涵盖。

何谓“可区分”，取决于实现以及所使用的 C 语言版本：

  • C90 的最低要求是前 31 个字符有效；
  • C99 的最低要求是前 63 个字符有效，每个通用字符或扩展源字符按一个字符计。

理由

如果两个标识符只在非有效字符上有差别，行为就是未定义的。

如果需要考虑可移植性，审慎的做法是按 C 标准规定的最低限度应用本规则。

标识符过长可能妨碍阅读代码。许多自动代码生成系统都会产生很长的标识符，但仍有充分理由把标识符长度控制在远低于上述限度的范围内。

原书示例

在下面的示例中，对于不具有外部链接的标识符，这里的实现支持 31 个有效字符，区分大小写。

标识符 engine_exhaust_gas_temperature_local 符合本规则。尽管它与标识符 engine_exhaust_gas_temperature_raw 不可区分，但两者位于不同的作用域。不过，它不符合 Rule 5.3。

/*             1234567890123456789012345678901*********       Characters */
extern int32_t engine_exhaust_gas_temperature_raw;
static int32_t engine_exhaust_gas_temperature_scaled;   /* Non-compliant */

void f ( void )
{
  /*        1234567890123456789012345678901*********          Characters */
  int32_t   engine_exhaust_gas_temperature_local;       /* Compliant     */
}

/*             1234567890123456789012345678901*********       Characters */
static int32_t engine_exhaust_gas_temp_raw;
static int32_t engine_exhaust_gas_temp_scaled;          /* Compliant     */
