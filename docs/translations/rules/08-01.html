Rule 8.1 · 显式指定类型

底本定位 §8.8 · PDF／印刷 71–72／63–64

原文译文

8.8　声明与定义

Rule 8.1　必须显式指定类型。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90

理由

C90 标准允许在某些情形下省略类型，此时隐式指定的类型是 int。可能用到隐式 int 的情形包括：

  • 对象声明；
  • 形参声明；
  • 成员声明；
  • typedef 声明；
  • 函数返回类型。

不显式写出类型可能会使人误解。例如，在下列声明中：

extern void g ( char c, const k );

k 的类型是 const int，而读者可能以为是 const char。

原书示例

以下是符合和不符合本规则的对象声明：

extern         x;   /* Non-compliant - implicit int type */
extern int16_t x;   /* Compliant - explicit type         */
const          y;   /* Non-compliant - implicit int type */
const int16_t  y;   /* Compliant - explicit type         */

以下是符合和不符合本规则的函数类型声明：

extern f ( void );                           /* Non-compliant - implicit
                                              * int return type          */
extern int16_t f ( void );                   /* Compliant                */

extern void g ( char c, const k );           /* Non-compliant - implicit
                                              * int for parameter k      */
extern void g ( char c, const int16_t k );   /* Compliant                */

以下是符合和不符合本规则的类型定义：

typedef ( *pfi ) ( void );             /* Non-compliant - implicit int
                                        * return type                    */
typedef int16_t ( *pfi ) ( void );     /* Compliant                      */
typedef void ( *pfv ) ( const x );     /* Non-compliant - implicit int
                                        * for parameter x                */
typedef void ( *pfv ) ( int16_t x );   /* Compliant                      */

以下是符合和不符合本规则的成员声明：

struct str
{
  int16_t x;   /* Compliant                                 */
  const   y;   /* Non-compliant - implicit int for member y */
} s;

另见

Rule 8.2

原书代码注释中译（按出现顺序）： 对象声明中，隐式 int 的 x、y 不符合；显式类型符合。函数返回类型或形参 k 的 int 若靠推断则不符合，显式写出符合。函数指针类型定义同理：pfi 的返回类型、pfv 的形参 x 不能隐含为 int。结构体中 x 符合，y 隐含为 int，不符合。
