Rule 5.1 · 可区分的外部标识符

底本定位 §8.5 · PDF 56–57／印刷 48–49

原文译文

8.5　标识符

Rule 5.1　不同的外部标识符必须可区分。

C90 [未定义 7]，C99 [未指定 7；未定义 28]

类别
必需（Required）
分析
可判定（Decidable），系统（System）
适用标准
C90、C99

进一步说明

本规则要求：不同的外部标识符，必须在实现规定的限度内可区分。

何谓“可区分”，取决于实现以及所使用的 C 语言版本：

  • C90 的最低要求是：外部标识符的前 6 个字符有效，但不要求区分大小写；
  • C99 的最低要求是：外部标识符的前 31 个字符有效，每个通用字符或对应的扩展源字符占 6 至 10 个字符。

实际上，许多实现提供的限度更高。例如，在 C90 实现中，外部标识符区分大小写、且至少前 31 个字符有效，是常见的做法。

理由

如果两个标识符只在非有效字符上有差别，行为就是未定义的。

如果需要考虑可移植性，审慎的做法是按 C 标准规定的最低限度应用本规则。

标识符过长可能妨碍阅读代码。许多自动代码生成系统都会产生很长的标识符，但仍有充分理由把标识符长度控制在远低于上述限度的范围内。

注： 在 C99 中，如果外部标识符含有一个扩展源字符，而该字符又没有对应的通用字符，C 标准未规定它占多少个字符。

原书示例

在下面的示例中，所有定义都在同一翻译单元内。这里的实现支持外部标识符有 31 个有效字符，区分大小写。

/*      1234567890123456789012345678901*********    Characters    */
int32_t engine_exhaust_gas_temperature_raw;
int32_t engine_exhaust_gas_temperature_scaled;   /* Non-compliant */

/*      1234567890123456789012345678901*********    Characters    */
int32_t engine_exhaust_gas_temp_raw;
int32_t engine_exhaust_gas_temp_scaled;          /* Compliant     */

在下面这个不符合规则的示例中，实现支持外部标识符有 6 个有效字符，不区分大小写。两个翻译单元中的标识符写法不同，但按其有效字符不能将两者区分开。

/* file1.c */
int32_t abc = 0;

/* file2.c */
int32_t ABC = 0;
