Rule 11.6 · void 指针与算术类型

底本定位 规则 PDF／印刷 107／99。

原文译文

Rule 11.6　不得在指向 void 的指针与算术类型之间进行强制转换。

C90 [未定义 29；实现定义 24]；C99 [未定义 21、41；实现定义 J.3.7(1)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

将整数转换为指向 void 的指针，可能产生未正确对齐的指针，导致未定义行为。

将指向 void 的指针转换为整数，可能产生所选整数类型无法表示的值，导致未定义行为。

任何非整数算术类型与指向 void 的指针之间的转换都是未定义的。

例外

值为 0 的整型常量表达式可强制转换为指向 void 的指针。

原书示例

void     *p;
uint32_t  u;

/* Non-compliant - implementation-defined */
p = ( void * ) 0x1234u;

/* Non-compliant - undefined              */
p = ( void * ) 1024.0f;

/* Non-compliant - implementation-defined */
u = ( uint32_t ) p;

原书代码注释中译（按出现顺序）： 从整型非零常量转为 void * 不符合，行为由实现定义；浮点数转为 void * 不符合，行为未定义；void * 转为整数不符合，行为由实现定义。
