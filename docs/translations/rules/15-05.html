Rule 15.5 · 把函数出口放在末尾

底本定位 PDF／印刷 134–135／126–127。

原文译文

Rule 15.5　函数应只有一个出口，且该出口应位于函数末尾。

[IEC 61508-3 表 B.9]、[ISO 26262-6 表 8]

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

一个函数不应有多于一条 return 语句。

使用 return 时，它应是构成函数体的复合语句中的最后一条语句。

理由

IEC 61508 和 ISO 26262 将单一出口作为采用模块化方法的要求之一。

提前返回可能导致无意间遗漏函数收尾代码。

若函数出口穿插在产生持久副作用的语句之间，就不容易判断执行函数时究竟会发生哪些副作用。

原书示例

下列不合规代码在校验函数形参时使用了提前返回。

bool_t f ( uint16_t n, char *p )
{
  if ( n > MAX )
  {
    return false;
  }

  if ( p == NULL )
  {
    return false;
  }

  return true;
}
