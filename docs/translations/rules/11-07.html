Rule 11.7 · 对象指针与非整数算术类型

底本定位 规则 PDF／印刷 107–108／99–100。

原文译文

Rule 11.7　不得在指向对象的指针与非整数算术类型之间进行强制转换。

C90 [未定义 29；实现定义 24]；C99 [未定义 21、41；实现定义 J.3.7(1)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

就本规则而言，非整数算术类型指下列类型之一：

  • 本质布尔型；
  • 本质字符型；
  • 本质枚举型；
  • 本质浮点型。

理由

将本质布尔型、本质字符型或本质枚举型转换为指向对象的指针，可能产生未正确对齐的指针，导致未定义行为。

将指向对象的指针转换为本质布尔型、本质字符型或本质枚举型，可能产生所选整数类型无法表示的值，导致未定义行为。

在指向对象的指针与本质浮点型之间进行任一方向的转换，都会导致未定义行为。

原书示例

int16_t  *p;
float32_t f;

f = ( float32_t ) p;   /* Non-compliant */
p = ( int16_t * ) f;   /* Non-compliant */

另见

Rule 11.4。

原书代码注释中译（按出现顺序）： 把指针转为浮点类型、把浮点值转为指针均不符合本规则。
