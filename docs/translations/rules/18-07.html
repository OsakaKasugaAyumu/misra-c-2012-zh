Rule 18.7 · 柔性数组成员与结构体赋值

底本定位 PDF／印刷 159／151。

原文译文

Rule 18.7　不得声明柔性数组成员。

C99 [未定义 59]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

柔性数组成员最可能与动态内存分配一起使用，而 Dir 4.12 和 Rule 21.3 禁止动态内存分配。

柔性数组成员的存在会改变 sizeof 运算符的行为，程序员可能对此始料未及。把包含柔性数组成员的结构体赋给另一个同类型的结构体，结果也可能不符合预期：该赋值只复制柔性数组成员起点之前的部分，不包括从该起点开始的元素。

原书示例

#include <stdlib.h>

struct s
{
  uint16_t len;
  uint32_t data[ ];   /* Non-compliant - flexible array member */
} str;

struct s *copy ( struct s *s1 )
{
  struct s *s2;

  /* Omit malloc ( ) return check for brevity */
  s2 = malloc ( sizeof ( struct s ) + ( s1->len * sizeof ( uint32_t ) ) );

  *s2 = *s1;          /* Only copies s1->len */

  return s2;
}

原书代码注释中译（依次）： （1）不合规：柔性数组成员。 （2）为简明起见，省略对 malloc() 返回值的检查。 （3）仅复制 s1->len。

另见

Dir 4.12、Rule 21.3。

源页核对： PDF 159：适用栏确为 C90、C99，所引未定义行为编号来自 C99。保留两项字段，不把“本条适用 C90”误写成“严格 C90 支持柔性数组”。
