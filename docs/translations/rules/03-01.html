Rule 3.1 · 注释中的注释起始符

底本定位 §8.3 · PDF 53／印刷 45

原文译文

8.3　注释

Rule 3.1　注释内部不得使用字符序列 /* 和 //。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

如果在 /* 注释中出现了注释起始序列 /* 或 //，很可能是因为漏写了结束注释的 */。

如果在 // 注释中出现注释起始序列，则很可能是有人用 // 将一段代码注释掉了。

例外

允许在 // 注释内出现 // 序列。

原书示例

请看下面的代码片段：

/* some comment, end comment marker accidentally omitted

<<New Page>>

Perform_Critical_Safety_Function( X );

/* this comment is non-compliant */

原书代码文字中译： 第一行：“一段注释，无意间漏写了注释结束标记”。<<New Page>> 表示换到新的一页。最后一行：“这条注释不合规”。

在审查含有函数调用的那一页时，人们会以为该行是会执行的代码。实际上，由于无意间漏写了注释结束标记，对该安全关键函数的调用不会执行。

在下面的 C99 示例中，// 注释的存在改变了程序的含义：

x = y // /*
      + z
      // */
    ;

这样得到的是 x = y + z;；如果没有那两处 // 注释起始序列，得到的就会是 x = y;。
