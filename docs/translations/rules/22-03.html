Rule 22.3 · 按文件身份比较流的打开区间

底本定位 PDF／印刷 183／175。

原文译文

Rule 22.3　不得让不同的流同时打开同一文件进行读访问和写访问。

C90 [实现定义 61]；C99 [实现定义 J.3.12(22)]

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

本条适用于使用标准库函数打开的文件。它也可能适用于执行环境提供的类似功能。

理由

如果通过不同的流既写又读同一文件，C 标准不规定其行为。

注： 允许多次以只读方式打开同一文件。

原书示例

#include <stdio.h>

void fn ( void )
{
  FILE *fw = fopen ( "tmp", "r+" );   /* "r+" opens for read/write */
  FILE *fr = fopen ( "tmp", "r" );    /* Non-compliant             */
}

原书代码注释中译（依次）： （1）r+ 以读写方式打开。 （2）不合规。

另见

Rule 21.6。
