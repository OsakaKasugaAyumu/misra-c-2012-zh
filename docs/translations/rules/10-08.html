Rule 10.8 · 对复合结果的强制转换

底本定位 规则 PDF／印刷 100／92。

原文译文

Rule 10.8　不得将复合表达式的值强制转换为不同的本质类型类别或较宽的本质类型。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

理由见关于复合运算符与复合表达式的导言（§8.10.3）。

不允许强制转换为较宽类型，因为结果可能因实现而异。考虑下例：

( uint32_t ) ( u16a + u16b );

在 16 位机器上，加法按 16 位进行，结果按模 2 回绕后才强制转换为 32 位。而在 32 位机器上，加法按 32 位进行，可以保留在 16 位机器上本会丢失的高位。

强制转换到同一本质类型类别中的较窄类型是可接受的，因为显式截短结果总会产生相同的信息损失。

原书示例

( uint16_t ) ( u32a + u32b )   /* Compliant                             */
( uint16_t ) ( s32a + s32b )   /* Non-compliant - different essential
                                *                 type category         */
( uint16_t ) s32a              /* Compliant     - s32a is not composite */
( uint32_t ) ( u16a + u16b )   /* Non-compliant - cast to wider
                                *                 essential type        */

另见

Rule 10.5、§8.10.3。

原书代码注释中译（按出现顺序）： 四式分别为：符合；不符合，本质类型类别不同；符合，s32a 不是复合表达式；不符合，转换到了较宽的本质类型。
