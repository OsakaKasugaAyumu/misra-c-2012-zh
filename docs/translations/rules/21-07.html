Rule 21.7 · 给十进制输入可判定的错误结果

底本定位 PDF／印刷 177／169。

原文译文

Rule 21.7　不得使用 <stdlib.h> 中的 atof、atoi、atol 和 atoll 函数。

C90 [未定义 90]；C99 [未定义 113]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

不得使用标识符 atof、atoi、atol，在 C99 中还不得使用 atoll；也不得展开与这些标识符中任何一个同名的宏。

理由

在无法转换字符串时，使用这些函数涉及未定义行为。

源页核对： PDF 177：理由用的是概括性的“无法转换”。不能把它当作各输入（没有数字、结果超出范围等）行为都相同的分类表；保留原文措辞，不用运行反例补写。
