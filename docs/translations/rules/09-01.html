Rule 9.1 · 自动存储期对象的首次读取

底本定位 §8.9 · PDF／印刷 83–84／75–76

原文译文

8.9　初始化

Rule 9.1　具有自动存储期的对象，其值在设定之前不得被读取。

C90 [未定义 41]，C99 [未定义 10、17]

类别
强制（Mandatory）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

就本规则而言，数组元素或结构体成员应各自视为一个独立对象。

理由

按照 C 标准，具有静态存储期的对象，除非经过显式初始化，否则会自动初始化为零。具有自动存储期的对象不会自动初始化，因而可能具有不确定值。

注： 自动对象的显式初始化有时也可能被忽略。当 goto 或 switch 语句跳转到某个标号而“绕过”该对象的声明时，就会发生这种情况：对象仍按预期得到声明，但任何显式初始化都会被忽略。

原书示例

void f ( bool_t b, uint16_t *p )
{
  if ( b )
  {
    *p = 3U;
  }
}

void g ( void )
{
  uint16_t u;

  f ( false, &u );

  if ( u == 3U )
  {
    /* Non-compliant - u has not been assigned a value */
  }
}

在下面这个不符合本规则的 C99 示例中，goto 语句跳过了 x 的初始化。

注： 此例也不符合 Rule 15.1。

{
  goto L1;

  uint16_t x = 10u;

L1:
  x = x + 1u;   /* Non-compliant - x has not been assigned a value */
}

另见

Rule 15.1、Rule 15.3

原书代码注释中译（按出现顺序）： u 没有被赋值，读取它不符合规则；第二例中 x 没有被赋值，读取它也不符合规则。
