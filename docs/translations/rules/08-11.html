Rule 8.11 · 外部数组声明的长度

底本定位 §8.8 · PDF／印刷 80／72

原文译文

Rule 8.11　声明具有外部链接属性的数组时，应当显式指定其大小。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则仅适用于非定义声明。定义数组时可以通过初始化隐式指定其大小。

理由

虽然可以声明不完整类型的数组并访问其元素，但能够明确确定数组大小时，这样做更安全。为每个声明提供大小信息，就可以检查各个声明是否一致。这也可能使静态检查器无需分析多个翻译单元就能进行一些数组边界分析。

原书示例

extern int32_t array1[ 10 ];   /* Compliant     */
extern int32_t array2[ ];      /* Non-compliant */

原书代码注释中译（按出现顺序）： 显式写出 10 的声明符合，方括号为空的声明不符合。
