Rule 16.3 · 各 switch 子句以无条件 break 结束

底本定位 PDF／印刷 139–140／131–132。

原文译文

Rule 16.3　每个 switch 子句都必须以一条无条件的 break 语句结束。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

如果开发者没有以 break 结束某个 switch 子句，控制流就会“贯穿”到下一个子句；若没有下一个子句，则会越过 switch 的末尾，进入其后的语句。贯穿到下一个子句有时是有意为之，但往往是错误。当前位于 switch 末尾的子句如果没有终止，将来可能贯穿到后来追加的子句中。

为使这类错误能够被发现，每个 switch 子句的最后一条语句都必须是 break；如果子句本身是复合语句，复合语句内的最后一条语句就必须是 break。

注： 按定义，switch 子句至少含有一条语句。连续的两个标号（case 或 default）之间没有语句，因此本条允许这种写法。

原书示例

switch ( x )
{
  case 0:
    break;          /* Compliant - unconditional break                */
  case 1:           /* Compliant - empty fall through allows a group  */
  case 2:
    break;          /* Compliant                                      */
  case 4:
    a = b;          /* Non-compliant - break omitted                  */
  case 5:
    if ( a == b )
    {
      ++a;
      break;        /* Non-compliant - conditional break              */
    }
  default:
    ;               /* Non-compliant - default must also have a break */
}

原书代码注释中译（依次）： （1）合规：无条件 break。 （2）合规：空的贯穿可将标号分为一组。 （3）合规。 （4）不合规：省略了 break。 （5）不合规：break 带有条件。 （6）不合规：default 也必须有 break。
