Rule 17.7 · 使用或明确弃用函数返回值

底本定位 PDF／印刷 149–150／141–142。

原文译文

Rule 17.7　返回类型非 void 的函数，其返回值必须被使用。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

调用函数却不使用返回值可能是个错误。如果确实不打算显式使用函数返回值，应将它转换为 void 类型。这样做起到了使用该值的作用，又不违反 Rule 2.2。

原书示例

uint16_t func ( uint16_t para1 )
{
  return para1;
}

uint16_t x;

void discarded ( uint16_t para2 )
{
  func ( para2 );            /* Non-compliant - value discarded */
  ( void ) func ( para2 );   /* Compliant                       */
  x = func ( para2 );        /* Compliant                       */
}

原书代码注释中译（依次）： （1）不合规：丢弃了返回值。 （2）合规。 （3）合规。

另见

Dir 4.7、Rule 2.2。
