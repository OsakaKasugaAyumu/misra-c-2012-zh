Rule 11.9 · 整型空指针常量与 NULL

底本定位 规则 PDF／印刷 109–110／101–102。

原文译文

Rule 11.9　宏 NULL 必须是整型空指针常量唯一允许使用的形式。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

值为 0 的整型常量表达式出现在以下任一上下文中时，必须来源于宏 NULL 的展开：

  • 作为赋给指针的值；
  • 作为 == 或 != 的一个操作数，而另一个操作数是指针；
  • 作为 ?: 的第二操作数，而第三操作数是指针；
  • 作为 ?: 的第三操作数，而第二操作数是指针。

忽略空白及外围括号后，这样的整型常量表达式必须代表 NULL 的完整展开结果。

注： 允许使用 (void *)0 形式的空指针常量，无论它是否由 NULL 展开而来。

理由

使用 NULL 而不是 0，可以明确表明此处要表达的是空指针常量。

原书示例

下例中，p2 的初始化符合本规则，因为整型常量表达式 0 并未出现在本规则禁止其出现的上下文中。

int32_t *p1 = 0;              /* Non-compliant */

int32_t *p2 = ( void * ) 0;   /* Compliant     */

下例中，p2 与 (void *)0 的比较符合本规则，因为整型常量表达式 0 是强制转换的操作数，并未出现在本规则禁止其出现的上下文中。

#define MY_NULL_1 0
#define MY_NULL_2 ( void * ) 0

if ( p1 == MY_NULL_1 )    /* Non-compliant */
{
}
if ( p2 == MY_NULL_2 )    /* Compliant     */
{
}

下例符合本规则，因为总是允许使用实现提供的宏 NULL，即使它展开为值为 0 的整型常量表达式也是如此。

/* Could also be stdio.h, stdlib.h and others */
#include <stddef.h>

extern void f ( uint8_t *p );

/* Compliant for any conforming definition of NULL, such as:
 *    0
 *    ( void * ) 0
 *    ( ( ( 0 ) ) )
 *    ( ( ( 1 - 1 ) ) )
 */
f ( NULL );

另见

Rule 11.4。

原书代码注释中译（按出现顺序）： p1 的初始化不符合，p2 的初始化符合；与 MY_NULL_1 比较不符合，与 MY_NULL_2 比较符合。取得 NULL 的头文件也可为 stdio.h、stdlib.h 等。对 NULL 的任何符合标准的定义，末尾的调用均符合规则；原注释依次列出 0、指针形式的零、多层括号包围的 0 和多层括号包围的 1 - 1。
