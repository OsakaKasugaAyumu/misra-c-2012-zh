Rule 21.9 · 用重复键验证自编查找与排序

底本定位 PDF／印刷 178／170。

原文译文

Rule 21.9　不得使用 <stdlib.h> 中的库函数 bsearch 和 qsort。

C90 [未指定 20、21]；C99 [未指定 41、42；未定义 176–178]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

不得使用标识符 bsearch、qsort，也不得展开与其中任何一个同名的宏。

理由

如果比较函数在比较元素时表现得不一致，或修改了任一元素，行为就是未定义的。

注： 对于比较结果相等的元素，其处理方式是未指定的。确保比较函数永不返回 0，就可以避免这里的未指定行为。当两个元素在其他方面相等时，比较函数可以返回一个值，表示它们在初始数组中的相对次序。

qsort 的实现很可能采用递归，因此对栈资源的需求未知。这对于嵌入式系统值得关注，因为这类系统的栈大小通常是固定的，而且往往很小。

源页核对： PDF 178：原书说可令比较函数永不返回 0，并举出用初始次序区分原本相等的元素；没有说明比较同一元素本身的情况。照录该注，它不是使用 qsort 的例外，也不据此构造不一致的比较器。
