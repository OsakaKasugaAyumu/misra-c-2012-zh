Rule 8.12 · 隐式确定的枚举值

底本定位 §8.8 · PDF／印刷 81／73

原文译文

Rule 8.12　在同一枚举项列表中，隐式指定的枚举常量的值必须是唯一的。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

隐式指定的枚举常量比其前一项的值大 1。若第一个枚举常量是隐式指定的，其值为 0。

显式指定的枚举常量的值就是相应常量表达式的值。

同一枚举列表中混用隐式和显式指定的常量，可能产生重复值。这种重复可能并非有意，可能导致意料之外的行为。

本规则要求把任何枚举常量值的重复都写明，以便清楚表达意图。

原书示例

下列示例中的枚举常量 green 和 yellow 被赋予相同的值。

/* Non-compliant - yellow replicates implicit green */
enum colour { red = 3, blue, green, yellow = 5 };

/* Compliant                                        */
enum colour { red = 3, blue, green = 5, yellow = 5 };

原书代码注释中译（按出现顺序）： 第一组不符合：yellow 重复隐式确定的 green 值；第二组符合。
