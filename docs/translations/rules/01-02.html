Rule 1.2 · 语言扩展

底本定位 §8.1 · PDF 46／印刷 38

原文译文

Rule 1.2　不应使用语言扩展。

类别
建议（Advisory）
分析
不可判定（Undecidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

与不使用语言扩展的程序相比，依赖语言扩展的程序可能较难移植。虽然标准要求符合标准的实现用文档说明它提供的所有语言扩展，但文档仍有可能没有完整描述它们在各种情形下的行为。

如果不采用本规则，则应在项目设计文档中说明使用每一项语言扩展的理由。还应记录将如何确保每项扩展得到正确使用，例如检查编译器及其诊断信息。

本文件承认，嵌入式系统中有使用语言扩展的必要。标准要求扩展不得改变任何严格符合标准的程序的行为。例如，标准规定二元逻辑运算符的结果一经确定，求值即停止；但某个编译器可能以扩展的方式对两个操作数都求值。这种扩展不符合标准，因为逻辑与运算符右操作数中的副作用将总是发生，从而产生不同的行为。
