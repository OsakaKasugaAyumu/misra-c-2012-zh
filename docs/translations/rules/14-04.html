Rule 14.4 · 控制表达式的本质布尔类型

底本定位 规则 PDF／印刷 129–130／121–122。

原文译文

Rule 14.4　if 语句的控制表达式和迭代语句的控制表达式都必须具有本质布尔类型。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

for 语句的控制表达式是可选的。本规则不要求提供此表达式，但若提供，它就必须具有本质布尔类型。

理由

强类型要求 if 语句或迭代语句的控制表达式具有本质布尔类型。

原书示例

int32_t *p, *q;

while ( p )           /* Non-compliant - p is a pointer */
{
}

while ( q != NULL )   /* Compliant                      */
{
}

while ( true )        /* Compliant                      */
{
}

extern bool_t flag;

while ( flag )        /* Compliant                      */
{
}

int32_t i;

if ( i )              /* Non-compliant                  */
{
}

if ( i != 0 )         /* Compliant                      */
{
}

另见

Rule 14.2、Rule 20.8。

原书代码注释中译（按出现顺序）： while ( p ) 不符合：p 是指针。与 NULL 比较以及使用 true 的两个 while 符合。第 130 页的 while ( flag ) 符合；if ( i ) 不符合；if ( i != 0 ) 符合。
