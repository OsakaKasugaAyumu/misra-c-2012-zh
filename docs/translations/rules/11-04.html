Rule 11.4 · 对象指针与整数

底本定位 规则 PDF／印刷 105–106／97–98。

原文译文

Rule 11.4　不应在指向对象的指针与整数类型之间进行转换。

C90 [未定义 20；实现定义 24]；C99 [未定义 21、34；实现定义 J.3.7(1)]

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

不应将指针转换为整数。不应将整数转换为指针。

理由

将整数转换为指向对象的指针，可能产生未正确对齐的指针，导致未定义行为。

将指向对象的指针转换为整数，可能产生所选整数类型无法表示的值，导致未定义行为。

注： C99 在 <stdint.h> 中声明的 intptr_t 和 uintptr_t 分别是能够表示指针值的有符号、无符号整数类型。尽管如此，本规则仍不允许在指向对象的指针与这两种类型之间转换，因为使用它们并不能避免指针未对齐所涉及的未定义行为。

应尽可能避免在指针与整数类型之间进行强制转换，但在寻址内存映射寄存器或使用其他硬件特有功能时，这种转换可能不可或缺。如果使用了整数与指针之间的强制转换，就应注意确保所得指针不会引发 Rule 11.3 讨论的未定义行为。

例外

具有整数类型的空指针常量可转换为指向对象的指针。

原书示例

uint8_t *PORTA = ( uint8_t * ) 0x0002;    /* Non-compliant */

uint16_t *p;

int32_t   addr = ( int32_t ) &p;          /* Non-compliant */
uint8_t  *q    = ( uint8_t * ) addr;      /* Non-compliant */
bool_t    b    = ( bool_t ) p;            /* Non-compliant */

enum etag { A, B } e = ( enum etag ) p;   /* Non-compliant */

另见

Rule 11.3、Rule 11.7、Rule 11.9。

原书代码注释中译（按出现顺序）： 从整数地址初始化 PORTA 不符合；取得整数 addr、把 addr 转回指针、把指针转为 bool_t 或枚举的四个写法也都不符合。
