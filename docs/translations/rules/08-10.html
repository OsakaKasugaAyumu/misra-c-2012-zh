Rule 8.10 · 内联函数的存储类

底本定位 §8.8 · PDF／印刷 80／72

原文译文

Rule 8.10　内联函数必须以 static 存储类声明。

C99 [未指定 20；未定义 67]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

理由

若内联函数声明为具有外部链接属性，但未在同一翻译单元中定义，则行为未定义。

调用具有外部链接属性的内联函数时，可能调用该函数的外部定义，也可能使用内联定义。虽然这不应影响被调用函数的行为，但可能影响执行时序，从而影响实时程序。

注： 可将内联函数的定义放在头文件中，从而使多个翻译单元都能使用它。
