Rule 21.1 · 查被定义或撤销的名字

底本定位 PDF／印刷 173–174／165–166。

原文译文

8.21　标准库

Rule 21.1　不得对保留标识符或保留宏名使用 #define 或 #undef。

C90 [未定义 54、57、58、62、71]

C99 [未定义 93、100、101、104、108、116、118、130]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本条适用于：

  • 以下划线开头的标识符或宏名；
  • C 标准第 7 节“库”中所述的文件作用域标识符；
  • C 标准第 7 节“库”中指明在标准头文件中定义的宏名。

本条也禁止对标识符 defined 使用 #define 或 #undef，因为这会导致标准明确规定的未定义行为。

本条不包括所适用的 C 标准在“库的未来发展方向”（Future Library Directions）一节中描述的那些标识符或宏名。

C 标准指出，可以定义与下列名字同名的宏：

  • 标准头文件中定义的宏，或
  • 标准头文件中声明的、具有文件作用域的标识符。

只要不包含该头文件，这种定义的行为就是有定义的。本规则不允许这样的定义，因为它们容易引起混淆。

注： 宏 NDEBUG 并非定义在标准头文件中，因此可以用 #define 定义它。

理由

保留标识符和保留宏名是留给实现使用的。撤销保留宏或改变其含义，可能导致未定义行为。

原书示例

#undef  __LINE__                 /* Non-compliant - begins with _        */
#define _GUARD_H 1               /* Non-compliant - begins with _        */
#undef  _BUILTIN_sqrt            /* Non-compliant - the implementation
                                  * may use _BUILTIN_sqrt for other
                                  * purposes, e.g. generating a sqrt
                                  * instruction                          */

#define defined                  /* Non-compliant - reserved identifier  */
#define errno my_errno           /* Non-compliant - library identifier   */
#define isneg( x ) ( ( x ) < 0 ) /* Compliant     - rule doesn't include
                                  *                 future library
                                  *                 directions           */

原书代码注释中译（依次）： （1）不合规：以下划线开头。 （2）不合规：以下划线开头。 （3）不合规：实现可能将 _BUILTIN_sqrt 用于其他目的，例如生成一条平方根指令。 （4）不合规：保留标识符。 （5）不合规：库标识符。 （6）合规：本规则不包括库的未来发展方向。
