Rule 3.2 · 单行注释中的行拼接

底本定位 §8.3 · PDF 54／印刷 46

原文译文

Rule 3.2　不得在 // 注释中使用行拼接。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

进一步说明

当 \ 字符后紧跟一个换行字符时，就会发生行拼接。如果源文件含有多字节字符，它们会在任何行拼接发生之前被转换为源字符集中的字符。

理由

如果含有 // 注释的源代码行以源字符集中的 \ 字符结尾，下一行就会成为这条注释的一部分。这可能无意中去掉本应保留的代码。

注： C90 和 C99 均在第 5.1.1.2(2) 节描述了行拼接。

原书示例

在下面这个不合规示例中，含有 if 关键字的物理行在逻辑上属于前一行，因而是注释。

extern bool_t b;

void f ( void )
{
  uint16_t  x = 0;   // comment \
  if ( b )
  {
    ++x;             /* This is always executed */
  }
}

原书代码注释中译： x 的初始化行标有“注释”，行末是反斜杠；++x; 一行的注释是“这一句总会执行”。
