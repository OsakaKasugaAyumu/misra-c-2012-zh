Rule 20.14 · 按物理文件栈核对条件指令

底本定位 PDF／印刷 172–173／164–165。

原文译文

Rule 20.14　所有 #else、#elif 和 #endif 预处理指令，都必须与各自对应的 #if、#ifdef 或 #ifndef 指令位于同一文件中。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

若控制代码块包含或排除的条件编译指令分散在多个文件中，容易造成混淆。要求每个 #if 都在同一文件内结束，可以降低代码在阅读时的复杂程度，减少维护时引入错误的机会。

注： 被包含文件中可以使用 #if 指令，前提是它们在同一文件内结束。

原书示例

/* file1.c */
#ifdef A               /* Compliant     */
#include "file1.h"
#endif
/* End of file1.c */

原书代码注释中译（依次）： （1）文件 file1.c。 （2）合规。 （3）file1.c 结束。

/* file2.c */
#if 1                  /* Non-compliant */
#include "file2.h"
/* End of file2.c*/

/* file1.h */
#if 1                  /* Compliant     */
#endif
/* End of file1.h */

/* file2.h */
#endif
/* End of file1.h */

原书代码注释中译（依次）： （1）文件 file2.c。 （2）不合规。 （3）file2.c 结束。 （4）文件 file1.h。 （5）合规。 （6）file1.h 结束。 （7）文件 file2.h。 （8）file1.h 结束。

源页核对： PDF 173：file2.h 片段末行的原注却写作 End of file1.h；原样保留并按原注中译，不据此更改文件归属。
