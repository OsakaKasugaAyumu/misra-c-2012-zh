Rule 11.1 · 函数指针与兼容类型

底本定位 规则 PDF／印刷 101–103／93–95。含 PDF 101（印刷 93）的 §8.11 导言。

原文译文

8.11　指针类型转换

指针类型可作如下分类：

  • 指向对象的指针；
  • 指向函数的指针；
  • 指向不完整类型的指针；
  • 指向 void 的指针；
  • 空指针常量，即值 0，也可将其强制转换为 void *。

C 标准所允许的涉及指针的转换仅有以下几种：

  • 从指针类型转换为 void；
  • 从指针类型转换为算术类型；
  • 从算术类型转换为指针类型；
  • 从一种指针类型转换为另一种指针类型。

虽然语言约束允许，但指针与整数类型以外的算术类型之间的转换是未定义的。

以下允许的指针转换不需要显式强制转换：

  • 从指针类型转换为 _Bool（仅 C99）；
  • 从空指针常量转换为指针类型；
  • 从指针类型转换为兼容的指针类型，前提是目标类型保留源类型的所有类型限定符；
  • 在指向对象或不完整类型的指针与 void *（或其限定形式）之间转换，前提是目标类型保留源类型的所有类型限定符。

在 C99 中，不属于上述指针转换子集的任何隐式转换都违反约束（C99 §6.5.4、§6.5.16.1）。

在 C90 中，不属于上述指针转换子集的任何隐式转换都会导致未定义行为（C90 §6.3.4、§6.3.16.1）。

指针类型与整数类型之间的转换由实现定义。

Rule 11.1　不得在函数指针与任何其他类型之间进行转换。

C90 [未定义 24、27–29]；C99 [未定义 21、23、39、41]

进一步说明

函数指针只能与指向兼容函数类型的指针相互转换。

理由

在函数指针与下列任一类型之间进行任一方向的转换，都会导致未定义行为：

  • 指向对象的指针；
  • 指向不完整类型的指针；
  • void *。

如果通过类型与被调用函数不兼容的指针调用函数，行为是未定义的。C 标准允许将函数指针转换为指向另一种函数类型的指针，也允许将整数转换为函数指针。本规则禁止这两种转换，以避免使用不兼容指针类型调用函数所引发的未定义行为。

例外

  1. 空指针常量可转换为函数指针；
  2. 函数指针可转换为 void；
  3. 函数类型可隐式转换为指向该函数类型的指针。

注： 例外 3 涵盖 C90 §6.2.2.1 及 C99 §6.3.2.1 所述的隐式转换。以下两种情况下常发生此类转换：

  • 直接调用函数，即使用函数标识符指明要调用的函数；
  • 把函数赋给函数指针。

原书示例

typedef void ( *fp16 ) ( int16_t n );
typedef void ( *fp32 ) ( int32_t n );

#include <stdlib.h>                     /* To obtain macro NULL          */

fp16 fp1 = NULL;                        /* Compliant - exception 1       */
fp32 fp2 = ( fp32 ) fp1;                /* Non-compliant - function
                                         * pointer into different
                                         * function pointer              */

if ( fp2 != NULL )                      /* Compliant - exception 1       */
{
}

fp16 fp3 = ( fp16 ) 0x8000;             /* Non-compliant - integer into
                                         * function pointer              */
fp16 fp4 = ( fp16 ) 1.0e6F;             /* Non-compliant - float into
                                         * function pointer              */

下例中，函数调用返回一个指向函数类型的指针。把返回值强制转换为 void 符合本规则。

typedef fp16 ( *pfp16 ) ( void );

pfp16 pfp1;

( void ) ( *pfp1 ( ) );   /* Compliant - exception 2 - cast function
                           * pointer into void                           */

以下示例展示了从函数类型到指向该函数类型的指针的合规隐式转换。

extern void f ( int16_t n );

f ( 1 );             /* Compliant - exception 3 - implicit conversion
                      * of f into pointer to function                    */
fp16 fp5 = f;        /* Compliant - exception 3                          */

原书代码注释中译（按出现顺序）： 包含标准头以取得 NULL。fp1 符合例外 1；转为不同的函数指针不符合；与 NULL 比较符合例外 1。将整数、浮点数分别转成函数指针都不符合。把函数指针转为 void 符合例外 2。直接调用时 f 隐式转换成函数指针，符合例外 3；赋给 fp5 也符合例外 3。

源页核对： PDF 101：§8.11 的分类列表把空指针常量与各类指针并列；它是表达式的性质，不是一种额外的 C 指针类型。本页保持原列表，不把分类方式当作类型定义。
