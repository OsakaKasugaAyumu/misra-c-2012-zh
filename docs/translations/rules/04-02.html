Rule 4.2 · 三字符组

底本定位 §8.4 · PDF 55／印刷 47

原文译文

Rule 4.2　不应使用三字符组。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

三字符组由两个问号和紧接其后的一个指定字符表示（例如 ??- 表示 ~，即波浪号；??) 表示 ]）。它们容易与两个问号的其他用法混淆。

注： 所谓的双字符组：

   <: :> <% %> %: %:%:

是允许的，因为它们是记号（token）。三字符组则不同：在预处理之前，程序中凡是出现它们的地方，都会进行替换。

原书示例

例如，字符串

"(Date should be in the form ??-??-??)"

的行为并非预期的那样；编译器实际将它解释为

"(Date should be in the form ~~]"
