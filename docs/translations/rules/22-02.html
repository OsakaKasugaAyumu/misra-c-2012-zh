Rule 22.2 · 区分内存块身份、所有者与别名

底本定位 PDF／印刷 182／174。

原文译文

Rule 22.2　只有经由标准库函数分配的内存块才可被释放。

C90 [未定义 92]；C99 [未定义 169]

类别
强制（Mandatory）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

分配内存的标准库函数是 malloc、calloc 和 realloc。

把内存块的地址传给 free 就会释放该块；把地址传给 realloc 则可能释放该块。内存块一经释放，就不再被视为已分配，因此之后不能再次释放。

理由

释放未分配的内存，或多次释放同一已分配内存块，都会导致未定义行为。

原书示例

#include <stdlib.h>

void fn ( void )
{
  int32_t a;

  /* Non-compliant - a does not point to allocated storage     */
  free ( &a );
}

void g ( void )
{
  char *p = ( char * ) malloc ( 512 );
  char *q = p;

  free ( p );

  /* Non-compliant - allocated block freed a second time       */
  free ( q );

  /* Non-compliant - allocated block may be freed a third time */
  p = ( char * ) realloc ( p, 1024 );
}

原书代码注释中译（依次）： （1）不合规：a 不指向已分配的存储。 （2）不合规：同一已分配块被第二次释放。 （3）不合规：该已分配块可能被第三次释放。

另见

Dir 4.12、Dir 4.13、Rule 21.3。

源页核对： PDF 182：free(&a) 前的英文注释以 a 为主语；实际传入的是 &a，是具有自动存储期的对象的地址。保留原注措辞，不将它误作动态分配。
