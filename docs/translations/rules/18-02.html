Rule 18.2 · 先核对两个指针属于哪个数组

底本定位 PDF／印刷 153／145。

原文译文

Rule 18.2　只有当两个指针所指的元素属于同一数组时，才允许将它们相减。

C90 [未定义 31]；C99 [未定义 45]

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

本条适用于以下形式的表达式：

pointer_expression_1 - pointer_expression_2

如果 pointer_expression_1 和 pointer_expression_2 不是分别指向同一数组中的元素或该数组的尾后位置，行为就未定义。

原书示例

#include <stddef.h>

void f1 ( int32_t *ptr )
{
  int32_t   a1[ 10 ];
  int32_t   a2[ 10 ];
  int32_t  *p1 = &a1[ 1 ];
  int32_t  *p2 = &a2[ 10 ];
  ptrdiff_t diff;

  diff = p1 - a1;           /* Compliant     */
  diff = p2 - a2;           /* Compliant     */
  diff = p1 - p2;           /* Non-compliant */
  diff = ptr - p1;          /* Non-compliant */
}

原书代码注释中译（依次）： （1）合规。 （2）合规。 （3）不合规。 （4）不合规。

另见

Dir 4.1、Rule 18.4。

源页核对： PDF 153：底本把 ptr - p1 标为不合规，但这段函数没有展示实参来源。保留原注；仅凭两个指针的类型不能断言其归属，审查其他代码时须追溯到调用点。
