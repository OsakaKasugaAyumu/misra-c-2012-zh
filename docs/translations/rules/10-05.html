Rule 10.5 · 显式转换的目标类别

底本定位 规则 PDF／印刷 97–98／89–90。

原文译文

Rule 10.5　不应将表达式的值强制转换为不适当的本质类型。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

下表给出应避免的强制转换；值被强制转换（显式转换）到第一列所列的本质类型类别。

本质类型类别：列为来源，行为目标
目标 ↓ ／来源 →布尔字符枚举有符号无符号浮点
布尔避免避免避免避免避免
字符避免避免
枚举避免避免避免*避免避免避免
有符号避免
无符号避免
浮点避免避免

* 注： 枚举类型可以强制转换为枚举类型，前提是目标为相同的本质枚举类型。这种强制转换是多余的。

把 void 强制转换为任何其他类型都会导致未定义行为，因此不得这样做。此情形由 Rule 1.3 涵盖。

理由

可以出于正当的功能需要引入显式强制转换，例如：

  • 改变后续算术运算所采用的类型；
  • 有意截短数值；
  • 为使意图清楚而把类型转换写明。

不过，某些显式强制转换被认为不适当：

  • 在 C99 中，转换为 _Bool 或向其赋值，结果总是 0 或 1。若转换为另一种被定义为本质布尔型的类型，则未必如此；
  • 转换为本质枚举型可能产生不属于该类型枚举常量集合的值；
  • 从本质布尔型转换到任何其他类型，不大可能有实际意义；
  • 浮点类型与字符类型之间没有精确的表示映射，因此在两者之间作转换没有意义。

例外

值为 0 或 1 的整型常量表达式，不论其符号性如何，都可以强制转换为定义为本质布尔型的类型。这样便可以实现非 C99 的布尔模型。

原书示例

( bool_t ) false    /* Compliant - C99 'false' is essentially Boolean */
( int32_t ) 3U      /* Compliant                                      */
( bool_t ) 0        /* Compliant - by exception                       */
( bool_t ) 3U       /* Non-compliant                                  */

( int32_t ) ena     /* Compliant                                      */
( enum enuma ) 3    /* Non-compliant                                  */
( char ) enc        /* Compliant                                      */
