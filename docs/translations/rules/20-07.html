Rule 20.7 · 检查完全展开后的括号

底本定位 PDF／印刷 167–168／159–160。

原文译文

Rule 20.7　宏形参展开后形成的表达式必须用圆括号括起。

[Koenig 78–81]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

如果某个宏形参展开所得的一个记号或一串记号构成表达式，那么在完全展开的宏中，该表达式必须符合以下条件之一：

  • 自身就是一个带圆括号的表达式；或
  • 被圆括号括起。

注： 这不一定要求给所有宏形参都加上圆括号；也可以在宏实参中提供圆括号。

理由

如果不使用圆括号，宏替换时运算符的优先级可能使结果不合预期。

如果宏形参并非用作表达式，就不需要这些圆括号，因为这时并不涉及运算符。

原书示例

在下面这个不合规的示例中，

#define M1( x, y ) ( x * y )

r = M1 ( 1 + 2, 3 + 4 );

宏展开后得到：

r = ( 1 + 2 * 3 + 4 );

表达式 1 + 2 和 3 + 4 分别来自形参 x 和 y 的展开，但两个表达式都没有被括号括起。结果表达式的值是 11，而原本期望的结果可能是 21。

要写成合规的形式，既可以给宏实参加括号，也可以另写一个在展开时插入括号的宏，例如：

r = M1 ( ( 1 + 2 ), ( 3 + 4 ) );   /* Compliant */

#define M2( x, y ) ( ( x ) * ( y ) )

r = M2 ( 1 + 2, 3 + 4 );           /* Compliant */

原书代码注释中译（依次）： （1）合规。 （2）合规。

下例合规，因为 x 的第一次展开用作 ## 的操作数，并不产生表达式。x 的第二次展开用作表达式，已按要求用圆括号括起。

#define M3( x ) a ## x = ( x )

int16_t M3 ( 0 );

下例合规，因为形参 M 展开为成员名，不产生表达式。形参 S 的展开产生一个结构体或联合体类型的表达式，因而确实需要圆括号。

#define GET_MEMBER( S, M ) ( S ).M

v = GET_MEMBER ( s1, minval );

下面的合规示例表明，并不总是需要把形参的每一次出现都用括号括起，虽然这往往是满足本规则最容易的做法。

#define F( X ) G( X )
#define G( Y ) ( ( Y ) + 1 )

int16_t x = F ( 2 );

完全展开的宏是 ( ( 2 ) + 1 )。沿展开过程回溯，值 2 来自宏 G 中形参 Y 的展开，而 Y 又来自宏 F 中形参 X 的展开。由于在完全展开的宏中 2 已被圆括号括起，所以代码合规。
