Rule 20.6 · 先界定宏实参，再辨认指令

底本定位 PDF／印刷 166–167／158–159。

原文译文

Rule 20.6　宏实参中不得出现看起来像预处理指令的记号。

C90 [未定义 50]；C99 [未定义 87]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

如果实参含有在其他位置本会充当预处理指令的记号序列，就会导致未定义行为。

原书示例

#define M( A ) printf ( #A )

#include <stdio.h>

void main ( void )
{
  M (
#ifdef SW            /* Non-compliant */
       "Message 1"
#else                /* Non-compliant */
       "Message 2"
#endif               /* Non-compliant */
    );
}

原书代码注释中译（依次）： （1）不合规。 （2）不合规。 （3）不合规。

上述代码可能打印

#ifdef SW "Message 1" #else "Message 2" #endif

也可能打印

"Message 2"

或者表现出其他行为。

源页核对： PDF 166–167：页首的第二种可能输出及“或者表现出其他行为”仍属于 20.6。原书保留 void main 和两种输出；它们不是验证预期。
