Rule 17.8 · 区分修改形参和修改所指对象

底本定位 PDF／印刷 150／142。

原文译文

Rule 17.8　不应修改函数形参。

类别
建议（Advisory）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

函数形参的行为与具有自动存储期的对象相同。C 语言虽允许修改形参，但这种用法可能令人困惑，与程序员的预期冲突。把形参复制到一个具有自动存储期的对象中，再修改副本，可能更容易理解。使用现代编译器时，这样做通常不会增加存储或执行时间开销。

不熟悉 C、但习惯于其他语言的程序员可能会修改形参，误以为调用函数也会受到这种修改的影响。

原书示例

int16_t glob = 0;

void proc ( int16_t para )
{
  para = glob;                /* Non-compliant */
}

void f ( char *p, char *q )
{
  p = q;                      /* Non-compliant */
  *p = *q;                    /* Compliant     */
}

原书代码注释中译（依次）： （1）不合规。 （2）不合规。 （3）合规。
