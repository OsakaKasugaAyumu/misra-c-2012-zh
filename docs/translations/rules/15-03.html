Rule 15.3 · 不跳入另一块或另一 switch 子句

底本定位 PDF／印刷 131–132／123–124。

原文译文

Rule 15.3　goto 语句所引用的任何标号，都必须声明在该语句所在的块内，或声明在包围该语句的某个块内。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

就本条而言，不由复合语句构成的 switch 子句也视同一个块。

理由

不加限制地使用 goto，可能使程序缺乏结构，极难理解。

禁止在不同块之间跳转或跳入嵌套块，有助于降低阅读代码时控制流的复杂程度。

注： 使用可变修改类型时，C99 的限制更严。若从具有可变修改类型的标识符的作用域之外跳入该作用域，就违反了约束。

原书示例

void f1 ( int32_t a )
{
  if ( a <= 0 )
  {
    goto L2;            /* Non-compliant */
  }

  goto L1;              /* Compliant     */

  if ( a == 0 )
  {
    goto L1;            /* Compliant     */
  }

  goto L2;              /* Non-compliant */

L1:
  if ( a > 0 )
  {
  L2:
    ;
  }
}

原书代码注释中译（依次）： （1）不合规。 （2）合规。 （3）合规。 （4）不合规。

下例中，标号 L1 定义在一个包围块中，该块包围了含有 goto 语句的块。然而，这次跳转从一个 switch 子句进入另一个子句；就本条而言，switch 子句视同块，因此这条 goto 语句不合规。

switch ( x )
{
  case 0:
    if ( x == y )
    {
      goto L1;
    }
    break;
  case 1:
    y = x;
L1:
    ++x;
    break;
  default:
    break;
}
