Rule 11.2 · 指向不完整类型的指针

底本定位 规则 PDF／印刷 103–104／95–96。

原文译文

Rule 11.2　不得在指向不完整类型的指针与任何其他类型之间进行转换。

C90 [未定义 29]；C99 [未定义 21、22、41]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

不得把指向不完整类型的指针转换为其他类型。也不得进行以指向不完整类型的指针为目标的转换。

尽管指向 void 的指针也是一种指向不完整类型的指针，本规则不适用于指向 void 的指针，因为它们由 Rule 11.5 涵盖。

理由

转换为指向不完整类型的指针或从这种指针转换，可能产生未正确对齐的指针，导致未定义行为。

在指向不完整类型的指针与浮点类型之间进行任一方向的转换，总会导致未定义行为。

有时使用指向不完整类型的指针隐去对象的表示。将这种指针转换为指向对象的指针会破坏这种封装。

例外

  1. 空指针常量可转换为指向不完整类型的指针。
  2. 指向不完整类型的指针可转换为 void。

原书示例

struct s;                   /* Incomplete type                         */
struct t;                   /* A different incomplete type             */
struct s *sp;
struct t *tp;
int16_t  *ip;

#include <stdlib.h>         /* To obtain macro NULL                    */

ip = ( int16_t  * ) sp;     /* Non-compliant                           */
sp = ( struct s * ) 1234;   /* Non-compliant                           */
tp = ( struct t * ) sp;     /* Non-compliant - casting pointer into a
                             * different incomplete type               */
sp = NULL;                  /* Compliant - exception 1                 */

struct s *f ( void );

( void ) f ( );             /* Compliant - exception 2                 */

另见

Rule 11.5。

原书代码注释中译（按出现顺序）： s 和 t 是两个不同的不完整类型；包含标准头以取得 NULL。前三次转换均不符合，其中第三次换成了指向另一不完整类型的指针。赋 NULL 符合例外 1，丢弃返回值符合例外 2。
