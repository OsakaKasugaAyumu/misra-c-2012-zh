Rule 20.12 · 对照同一实参的展开名与原拼写

底本定位 PDF／印刷 171／163。

原文译文

Rule 20.12　对于用作 # 或 ## 运算符操作数的宏形参，如果它本身还会进一步进行宏替换，则它只能用作这两个运算符的操作数。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

宏形参用作 # 或 ## 的操作数时，在使用前不会先展开。同一个形参若出现在替换文本的其他位置，则会被展开。如果该形参本身还会进行宏替换，在同一个宏替换文本中混用这些上下文，可能与开发者的预期不符。

原书示例

在下面的不合规示例中，宏形参 x 被替换为 AA。在不作为 ## 的操作数时，AA 还会进一步进行宏替换。

#define AA        0xffff
#define BB( x )   ( x ) + wow ## x   /* Non-compliant */

void f ( void )
{
  int32_t wowAA = 0;

  /* Expands as wowAA = ( 0xffff ) + wowAA; */
  wowAA = BB ( AA );
}

原书代码注释中译（依次）： （1）不合规。 （2）展开为 wowAA = ( 0xffff ) + wowAA;。

在下面的合规示例中，宏形参 X 不会再进行宏替换。

int32_t speed;
int32_t speed_scale;
int32_t scaled_speed;

#define SCALE( X ) ( ( X ) * X ## _scale )

/* expands to scaled_speed = ( ( speed ) * speed_scale ); */
scaled_speed = SCALE ( speed );

原书代码注释中译（依次）： （1）展开为 scaled_speed = ( ( speed ) * speed_scale );。
