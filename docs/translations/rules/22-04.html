Rule 22.4 · 将打开模式传递到写入辅助函数

底本定位 PDF／印刷 184／176。

原文译文

Rule 22.4　不得尝试向以只读方式打开的流写入数据。

类别
强制（Mandatory）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

对于尝试向只读流写入的情况，C 标准不规定其行为。因此，向只读流写入数据被认为是不安全的。

原书示例

#include <stdio.h>

void fn ( void )
{
  FILE *fp = fopen ( "tmp", "r" );

  ( void ) fprintf ( fp, "What happens now?" );   /* Non-compliant */

  ( void ) fclose ( fp );
}

原书代码注释中译（依次）： （1）不合规。
