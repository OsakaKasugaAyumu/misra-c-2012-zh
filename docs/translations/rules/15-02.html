Rule 15.2 · 只向同一函数内的后续标号跳转

底本定位 PDF／印刷 130–131／122–123。

原文译文

Rule 15.2　goto 语句必须跳转到同一函数内在其后声明的标号。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

不加限制地使用 goto，可能使程序缺乏结构，极难理解。

限制 goto 的使用、禁止向后跳转，可以保证只有使用语言提供的迭代语句才会发生迭代，从而有助于降低阅读代码时控制流的复杂程度。

原书示例

void f ( void )
{
  int32_t j = 0;

L1:
  ++j;

  if ( 10 == j )
  {
    goto L2;         /* Compliant     */
  }

  goto L1;           /* Non-compliant */

L2:
  ++j;
}

原书代码注释中译（依次）： （1）合规。 （2）不合规。

另见

Rule 15.1、Rule 15.3、Rule 15.4。
