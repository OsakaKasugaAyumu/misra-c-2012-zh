Rule 20.5 · 追踪宏在两个定义之间的状态

底本定位 PDF／印刷 166／158。

原文译文

Rule 20.5　不宜使用 #undef。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

使用 #undef 可能使人难以分辨在翻译单元的某个位置究竟有哪些宏仍然存在。

原书示例

#define QUALIFIER volatile

#undef QUALIFIER             /* Non-compliant */

void f ( QUALIFIER int32_t p )
{
  while ( p != 0 )
  {
    ;                        /* Wait...  */
  }
}
