8.20　预处理指令

Rule 20.1　#include 指令之前宜仅出现预处理指令或注释。

C90 [未定义 56]；C99 [未定义 96、97]

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则须应用于预处理发生之前的文件内容。

理由

为使代码易读，一个代码文件中的所有 #include 指令宜集中放在靠近文件开头的位置。

此外，在声明或定义内部用 #include 包含标准头文件，或者在包含相应的标准头文件之前使用标准库的某一部分，都会导致未定义行为。

原书示例

/* f.h */
xyz = 0;

/* f.c */

int16_t
#include "f.h"    /* Non-compliant */

/* f1.c */
#define F1_MACRO

#include "f1.h"   /* Compliant     */
#include "f2.h"   /* Compliant     */

int32_t i = 0;

#include "f3.h"   /* Non-compliant */

原书代码注释中译（依次）： （1）文件 f.h。 （2）文件 f.c。 （3）不合规。 （4）文件 f1.c。 （5）合规。 （6）合规。 （7）不合规。
