Rule 15.1 · 限制使用 goto

底本定位 PDF／印刷 130／122。

原文译文

§8.15　控制流

Rule 15.1　不应使用 goto 语句。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

不加限制地使用 goto，可能使程序缺乏结构，极难理解。

在某些情况下，全面禁止 goto 会迫使开发者引入标志来保证控制流正确；这些标志本身可能还不如被替换的 goto 清楚。因此，若不遵循本条，只要符合 Rule 15.2 和 Rule 15.3 的指导，就允许有限制地使用 goto。

另见

Rule 9.1、Rule 15.2、Rule 15.3、Rule 15.4。
