Rule 20.3 · 在宏替换之后核对头文件名

底本定位 PDF／印刷 164–165／156–157。

原文译文

Rule 20.3　#include 指令之后必须是 <filename> 或 "filename" 形式的记号序列。

C90 [未定义 48]；C99 [未定义 85]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则在宏替换完成后适用。

理由

如果 #include 指令没有采用下列形式之一，行为就未定义：

  • #include <filename>
  • #include "filename"

原书示例

#include "filename.h"         /* Compliant     */
#include <filename.h>         /* Compliant     */
#include another.h            /* Non-compliant */

#define HEADER "filename.h"
#include HEADER               /* Compliant */
#define FILENAME file2.h
#include FILENAME             /* Non-compliant */

#define BASE "base"
#define EXT  ".ext"
#include BASE EXT             /* Non-compliant - strings are concatenated
                               *                 after preprocessing     */

#include "./include/cpu.h"    /* Compliant - filename may include a path */

原书代码注释中译（依次）： （1）合规。 （2）合规。 （3）不合规。 （4）合规。 （5）不合规。 （6）不合规：字符串在预处理之后才拼接。 （7）合规：文件名可以包含路径。
