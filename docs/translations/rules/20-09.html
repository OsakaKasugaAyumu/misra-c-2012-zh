Rule 20.9 · 把未定义、定义为零和定义为非零分开

底本定位 PDF／印刷 169／161。

原文译文

Rule 20.9　#if 或 #elif 预处理指令的控制表达式中使用的所有标识符，在求值前都必须已由 #define 定义。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

除了使用 #define 预处理指令，标识符实际上也可能以其他由实现定义的方式得到定义。例如，某些实现支持：

  • 使用编译器命令行选项，例如 -D，使标识符能在翻译前得到定义；
  • 使用环境变量达到同样的效果；
  • 使用编译器提供的预定义标识符。

理由

若试图在预处理指令中使用尚未定义的宏标识符，预处理器就会把它当作值为零。这可能与开发者的预期不符。

原书示例

下列示例假定宏 M 未定义。

#if M == 0        /* Non-compliant                                */
                  /* Does 'M' expand to zero or is it undefined?  */
#endif

#if defined ( M ) /* Compliant - M is not evaluated               */
#if M == 0        /* Compliant - M is known to be defined         */
                  /* 'M' must expand to zero.                     */
#endif
#endif

/* Compliant - B is only evaluated in ( B == 0 ) if it is defined */
#if defined ( B ) && ( B == 0 )
#endif

原书代码注释中译（依次）： （1）不合规。 （2）M 是展开为零，还是未定义？ （3）合规：没有对 M 求值。 （4）合规：已知 M 已定义。 （5）此时 M 必然展开为零。 （6）合规：仅在 B 已定义时才会在 ( B == 0 ) 中对它求值。
