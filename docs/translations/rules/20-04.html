Rule 20.4 · 用语言模式和标识符探针区分关键字

底本定位 PDF／印刷 165／157。

原文译文

Rule 20.4　不得定义与关键字同名的宏。

C90 [未定义 56]；C99 [未定义 98]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则适用于所有关键字，包括用于实现语言扩展的关键字。

理由

利用宏改变关键字的含义容易引起混淆。如果某个与关键字同名的宏正处于已定义状态，此时包含标准头文件，行为就未定义。

原书示例

下例不合规，因为它改变了关键字 int 的作用。在该宏生效期间包含标准头文件会导致未定义行为。

#define int some_other_type
#include <stdlib.h>

下例表明：重新定义关键字 while 不合规，而定义一个展开为语句的宏则符合本条。

#define while( E ) for ( ; ( E ) ; )  /* Non-compliant - redefined while */
#define unless( E ) if ( ! ( E ) )    /* Compliant                       */

#define seq( S1, S2 ) do { \
   S1; S2; } while ( false )          /* Compliant                       */
#define compound( S ) { S; }          /* Compliant                       */

原书代码注释中译（依次）： （1）不合规：重新定义了 while。 （2）合规。 （3）合规。 （4）合规。

下例符合 C90 下的本条要求，但在 C99 下不符合，因为 inline 在 C90 中不是关键字。

/* Remove inline if compiling for C90 */
#define inline

原书代码注释中译（依次）： （1）如果按 C90 编译，就移除 inline。
