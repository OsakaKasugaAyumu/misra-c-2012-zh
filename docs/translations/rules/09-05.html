Rule 9.5 · 使用指定初始化器时的数组大小

底本定位 §8.9 · PDF／印刷 88–89／80–81

原文译文

Rule 9.5　使用指定初始化器初始化数组对象时，必须显式指定数组大小。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

进一步说明

本规则同样适用于作为柔性数组成员的数组子对象。

理由

如果不显式指定数组的大小，大小就取决于所有已初始化元素中最高的下标。使用指定初始化器时，哪个初始化项的下标最高可能并不总是清楚，尤其是在初始化器包含大量元素时。

为使意图明确，必须显式声明数组大小。如果在程序开发过程中更改已初始化元素的下标，这样做能提供一定的保护，因为初始化超出数组边界的元素违反约束（C99 第 6.7.8 节）。

原书示例

/* Non-compliant - probably unintentional to have single element */
int a1[ ] = { [ 0 ] = 1 };

/* Compliant                                                     */
int a2[ 10 ] = { [ 0 ] = 1 };

原书代码注释中译（按出现顺序）： a1 不符合：很可能并非有意只保留一个元素。a2 显式写出大小，符合。

源页核对： PDF 88 明说范围包括柔性数组成员；这不是允许违反 C 约束来初始化柔性数组成员。本例未验证任何编译器扩展。PDF 89 上半页的理由和两个数组写法均已收录，未收 §8.10。
