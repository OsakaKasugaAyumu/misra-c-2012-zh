Rule 8.8 · 内部链接声明中的 static

底本定位 §8.8 · PDF／印刷 78–79／70–71

原文译文

Rule 8.8　具有内部链接属性的对象和函数，其所有声明都必须使用 static 存储类说明符。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

由于定义也是声明，本规则同样适用于定义。

理由

C 标准指出：若对象或函数使用 extern 存储类说明符声明，而该对象或函数的另一声明已经可见，则其链接属性由先前的声明指定。这容易引起误解，因为人们可能以为 extern 存储类说明符会产生外部链接属性。因此，对具有内部链接属性的对象和函数，必须一致地使用 static 存储类说明符。

原书示例

static int32_t x = 0;        /* definition: internal linkage  */
extern int32_t x;            /* Non-compliant                 */

static int32_t f ( void );   /* declaration: internal linkage */
int32_t f ( void )           /* Non-compliant                 */
{
  return 1;
}

static int32_t g ( void );   /* declaration: internal linkage */
extern int32_t g ( void )    /* Non-compliant                 */
{
  return 1;
}

原书代码注释中译（按出现顺序）： x 的定义为内部链接，后续 extern 声明不符合。f、g 的首次声明都是内部链接；两者的定义都不符合。
