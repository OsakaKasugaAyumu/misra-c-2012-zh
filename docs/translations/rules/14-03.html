Rule 14.3 · 恒定的控制表达式

底本定位 规则 PDF／印刷 127–129／119–121。

原文译文

Rule 14.3　控制表达式不得恒定不变。

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

本规则适用于：

  • if、while、for、do … while 和 switch 语句的控制表达式；
  • ?: 运算符的第一操作数。

理由

控制表达式的值若恒定不变，可能意味着有编程错误。因恒定表达式的存在而不可达的代码，可能被编译器移除。例如，这可能会从可执行程序中移除防御性代码。

例外

  1. 允许使用恒定式构成无限循环。
  2. 允许 do … while 循环使用求值为 0 的本质布尔型控制表达式。

原书示例

s8a = ( u16a < 0u ) ? 0 : 1;    /* Non-compliant - u16a always >= 0 */

if ( u16a <= 0xffffu )
{
                                /* Non-compliant - always true      */
}

if ( 2 > 3 )
{
                                /* Non-compliant - always false     */
}

for ( s8a = 0; s8a < 130; ++s8a )
{
                                /* Non-compliant - always true      */
}

if ( ( s8a < 10 ) && ( s8a > 20 ) )
{
                                /* Non-compliant - always false     */
}

if ( ( s8a < 10 ) || ( s8a > 5 ) )
{
                                /* Non-compliant - always true      */
}

while ( s8a > 10 )
{
  if ( s8a > 5 )
  {
                                /* Non-compliant - s8a not volatile */
  }
}

while ( true )
{
  /* Compliant by exception 1 */
}

do
{
  /* Compliant by exception 2 */
} while ( 0u == 1u );

const uint8_t numcyl = 4u;

/*
 * Non-compliant - compiler is permitted to assume that numcyl always
 * has value 4
 */
if ( numcyl == 4u )
{
}

const volatile uint8_t numcyl_cal = 4u;

/*
 * Compliant - compiler assumes numcyl_cal may be changed by
 * an external method, e.g. automotive calibration tool, even
 * though the program cannot modify its value
 */
if ( numcyl_cal == 4u )
{
}

uint16_t n;     /* 10 <= n <= 100 */
uint16_t sum;

sum = 0;

for ( uint16_t i = ( n - 6u ); i < n; ++i )
{
  sum += i;
}

if ( ( sum % 2u ) == 0u )
{
  /*
   * Non-compliant - sum is the sum of 6 consecutive non-negative
   * integers so must be an odd number. The controlling expression
   * of the if statement will always be false.
   */
}

另见

Rule 2.1、Rule 14.2。

原书代码注释中译（按出现顺序）： u16a 总是大于等于 0，第一项不符合；随后两个 if 的条件分别恒真、恒假。for 的比较恒真；其后两个组合条件分别恒假、恒真，均不符合。嵌套的 if 不符合，s8a 并非 volatile。无限循环符合例外 1；do … while 符合例外 2。编译器可以假定 numcyl 总为 4，因此该 if 不符合；numcyl_cal 可由汽车标定工具等外部手段更改，即使程序本身不能修改其值，编译器也按可能变化处理，此项符合。末例给定 10 ≤ n ≤ 100，六个连续非负整数之和必为奇数，故 if 的控制表达式恒假，不符合。
