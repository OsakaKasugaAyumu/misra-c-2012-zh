Rule 16.1 · 按规定的文法组织 switch

原文译文

§8.16　switch 语句

Rule 16.1　所有 switch 语句都必须具有规定的结构。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

如果一条 switch 语句属于下列语法规则所规定的 C switch 语句子集，就应视为结构正确。如果这里给出的语法规则与 C 标准中定义的规则同名，那么在该 switch 语句的范围内，以下规则取代标准版本；除此以外，标准中给出的所有语法规则均保持不变。

switch-statement:
switch ( switch-expression ) { case-label-clause-list final-default-clause-list }
switch ( switch-expression ) { initial-default-clause-list case-label-clause-list }
case-label-clause-list:
case-clause-list
case-label-clause-list case-clause-list
case-clause-list:
case-label switch-clause
case-label case-clause-list
case-label:
case constant-expression:
final-default-clause-list:
default: switch-clause
case-label final-default-clause-list
initial-default-clause-list:
default: switch-clause
default: case-clause-list
switch-clause:
statement-listopt break;
C90: { declaration-listopt statement-listopt break; }
C99: { block-item-listopt break; }

除非这套语法明确允许，case 和 default 关键字不得出现在 switch 语句体内的任何位置。

注： “另见”所列规则详细阐述了本条对 switch 的某些限制。因此，同一段代码可能既违反本条，也违反其中一条更具体的规则。

注： 在专门针对 switch 语句的各条规则中，“switch 标号”指 case 标号或 default 标号。

理由

C 语言对 switch 语句的语法限制并不十分严格，允许出现复杂、缺乏结构的行为。本条与其他相关规则为 switch 语句规定了简单而一致的结构。
