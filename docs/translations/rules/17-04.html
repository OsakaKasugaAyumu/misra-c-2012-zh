Rule 17.4 · 让非 void 函数所有出口都返回值

底本定位 PDF／印刷 146–147／138–139。

原文译文

Rule 17.4　对于返回类型非 void 的函数，每一条退出路径都必须显式执行一条带表达式的 return 语句。

C90 [未定义 43]；C99 [未定义 82]

类别
强制（Mandatory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

return 语句中的表达式给出函数的返回值。如果非 void 函数没有返回值，而调用函数又使用了这个返回值，行为就未定义。为避免这种情况，对非 void 函数要保证：

  • 每条 return 语句都有表达式；并且
  • 控制流不可能在没有遇到 return 语句的情况下到达函数末尾。

注： C99 的约束要求非 void 函数中的每条 return 语句都返回一个值。

原书示例

int32_t absolute ( int32_t v )
{
  if ( v < 0 )
  {
    return v;
  }

  /*
   * Non-compliant - control can reach this point without
   * returning a value
   */
}

uint16_t lookup ( uint16_t v )
{
  if ( ( v < V_MIN ) || ( v > V_MAX ) )
  {
    /* Non-compliant - no value returned. Constraint in C99 */
    return;
  }

  return table[ v ];
}

原书代码注释中译（依次）： （1）不合规：控制流可能在没有返回值的情况下到达这里。 （2）不合规：未返回值。在 C99 中违反约束。

另见

Rule 15.5。

源页核对： PDF 147：函数名为 absolute，而负值分支原样返回 v，不是 -v。保留原书代码，本例讨论的是另一条路径缺少返回值，不把它改写成绝对值实现。
