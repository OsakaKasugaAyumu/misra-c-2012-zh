Rule 13.1 · 初始化器列表中的持久副作用

底本定位 规则 PDF／印刷 116／108。

原文译文

8.13　副作用

Rule 13.1　初始化器列表不得含有持久副作用。

C99 [未指定 17、22]

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C99

理由

C90 限定具有聚合类型的自动对象，其初始化器只能包含常量表达式。C99 则允许自动聚合对象的初始化器包含在运行时求值的表达式，也允许使用相当于匿名已初始化对象的复合字面量。求初始化器列表中各表达式的值时，副作用发生的顺序未指定；如果这些副作用是持久的，初始化的行为就无法预测。

原书示例

volatile uint16_t v1;

void f ( void )
{
  /* Non-compliant - volatile access is persistent side effect */
  uint16_t a[ 2 ] = { v1, 0 };
}

void g ( uint16_t x, uint16_t y )
{
  /* Compliant - no side effects                               */
  uint16_t a[ 2 ] = { x + y, x - y };
}

uint16_t x = 0u;

extern void p ( uint16_t a[ 2 ] );

void h ( void )
{
  /* Non-compliant - two side effects                          */
  p ( ( uint16_t[ 2 ] ) { x++, x++ } );
}

原书代码注释中译（按出现顺序）： 第一项不符合：访问 volatile 对象是持久副作用。第二项符合：没有副作用。复合字面量一项不符合：有两个副作用。
