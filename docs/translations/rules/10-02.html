Rule 10.2 · 字符加减的方向与结果

底本定位 规则 PDF／印刷 93／85。

原文译文

Rule 10.2　本质字符型表达式不得以不适当的方式用于加法和减法运算。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

适当的用法如下：

  1. 对于 + 运算符，一个操作数必须具有本质字符类型，另一个必须具有本质有符号或本质无符号类型。运算结果具有本质字符类型。
  2. 对于 - 运算符，第一个操作数必须具有本质字符类型；第二个必须具有本质有符号、本质无符号或本质字符类型。若两个操作数均为本质字符型，结果就具有标准类型（在这种情形下通常为 int）；否则结果具有本质字符类型。

理由

本质字符型表达式（字符数据）不得用于算术计算，因为这些数据不表示数值。允许上述用法，是因为它们可以用于合理地处理字符数据。例如：

  • 两个本质字符型操作数相减，可用于在 '0' 至 '9' 的数字字符与相应序数值之间进行转换；
  • 本质字符型与本质无符号型相加，可用于把序数值转换为 '0' 至 '9' 中对应的数字字符；
  • 从本质字符型减去本质无符号型，可用于将小写字符转换为大写字符。

原书示例

以下示例符合本规则：

'0' + u8a   /* Convert u8a to digit   */
s8a + '0'   /* Convert s8a to digit   */
cha - '0'   /* Convert cha to ordinal */
'0' - s8a   /* Convert -s8a to digit  */

以下示例不符合本规则：

s16a - 'a'
'0' + f32a
cha + ':'
cha - ena
