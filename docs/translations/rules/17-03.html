Rule 17.3 · 在 C90 调用点提供可见声明

底本定位 PDF／印刷 146／138。

原文译文

Rule 17.3　不得隐式声明函数。

C90 [未定义 6、22、23]

类别
强制（Mandatory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90

理由

如果函数调用处有可见的原型，语言约束会保证实参数量与形参数量一致，而且每个实参都可以赋给其对应的形参。

如果函数是隐式声明的，C90 编译器会假定其返回类型为 int。隐式函数声明不提供原型，所以编译器不知道形参的个数和类型。这样，传递实参和赋用返回值时可能发生不恰当的类型转换，还可能出现其他未定义行为。

原书示例

若函数 power 声明如下：

extern double power ( double d, int n );

但在下列代码处看不到该声明，就会发生未定义行为。

void func ( void )
{
  /* Non-compliant - return type and both argument types incorrect */
  double sq1 = power ( 1, 2.0 );
}

原书代码注释中译（依次）： 不合规：返回类型和两个实参的类型都不正确。

另见

Rule 8.2、Rule 8.4。
