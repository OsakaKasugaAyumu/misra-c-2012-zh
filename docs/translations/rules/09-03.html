Rule 9.3 · 数组的部分初始化

底本定位 §8.9 · PDF／印刷 86–87／78–79

原文译文

Rule 9.3　不得对数组只作部分初始化。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

若显式初始化了数组对象或子对象中的任何一个元素，则必须显式初始化该对象或子对象的全部元素。

理由

对每个元素提供显式初始化，能清楚表明每个元素都经过了考虑。

例外

  1. 可用形式为 { 0 } 的初始化器显式初始化数组对象或子对象的全部元素。
  2. 可以使用初始化器完全由指定初始化项组成的数组，例如用它进行稀疏初始化。
  3. 用字符串字面量初始化的数组不必为每个元素都提供一个初始化项。

原书示例

/* Compliant */
int32_t x[ 3 ] = { 0, 1, 2 };

/* Non-compliant - y[ 2 ] is implicitly initialized */
int32_t y[ 3 ] = { 0, 1 };

/* Non-compliant - t[ 0 ] and t[ 3 ] are implicitly initialized */
float32_t t[ 4 ]  = { [ 1 ] = 1.0f, 2.0f };

/* Compliant - designated initializers for sparse matrix */
float32_t z[ 50 ] = { [ 1 ] = 1.0f, [ 25 ] = 2.0f };

在下面这个符合本规则的示例中，数组 arr 的每一个元素都得到了初始化：

float32_t arr[ 3 ][ 2 ] =
{
  { 0.0f, 0.0f },
  { PI / 4.0f, -PI / 4.0f },
  { 0 }   /* initializes all elements of array subobject arr[ 2 ] */
};

在下例中，数组的第 6 至第 9 号元素被隐式初始化为 '\0'：

char h[ 10 ] = "Hello";   /* Compliant by Exception 3 */

原书代码注释中译（按出现顺序）： x 符合；y 不符合，y[2] 隐式初始化。t 不符合，第 0、3 号元素隐式初始化；z 使用指定初始化项表示稀疏矩阵，符合。{0} 初始化 arr[2] 的所有元素；h 按例外 3 符合。
