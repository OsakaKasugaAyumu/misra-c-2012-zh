Rule 8.2 · 函数原型与具名形参

底本定位 §8.8 · PDF／印刷 72–74／64–66

原文译文

Rule 8.2　函数类型必须采用原型形式，并为形参命名。

C90 [未定义 22–25]，C99 [未定义 36–39、73、79]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

早期的 C 通常称为 K&R C [30]，它没有提供机制来对照相应形参检查实参的数量或类型。在 K&R C 中，对象或函数的类型不必声明，因为对象的默认类型和函数的默认返回类型都是 int。

C90 标准引入了函数原型，即一种声明形参类型的函数声明符。这使得可以对照形参类型检查实参类型，也可以检查实参数量，但原型指定接受可变数量实参时除外。出于与已有代码向后兼容的考虑，C90 标准并未要求使用函数原型。出于同一原因，它仍允许省略类型，此时类型默认为 int。

C99 标准从语言中移除了默认 int 类型，但仍允许 K&R 风格的函数类型：在这种形式的声明中无法提供形参类型信息，在定义中则可选择是否提供这些信息。

实参与形参的数量或类型不匹配，或者函数的预期返回类型与实际返回类型不匹配，都可能产生未定义行为。本规则连同 Rule 8.1 和 Rule 8.4，要求显式指定形参类型和函数返回类型，目的就是避免这种未定义行为。Rule 17.3 确保在函数调用处可以获得这些信息，从而要求编译器对检测到的任何不匹配给出诊断。

本规则还要求为声明中的所有形参指定名称。形参名能提供与函数接口有关的有用信息；声明与定义之间的不一致可能表明存在编程错误。

注： 空形参列表在原型中无效。如果函数类型没有形参，其原型形式使用关键字 void。

原书示例

第一个示例给出了若干函数的声明，以及其中一些函数的相应定义。

/* Compliant                                                 */
extern int16_t func1 ( int16_t n );

/* Non-compliant - parameter name not specified              */
extern void func2 ( int16_t );

/* Non-compliant - not in prototype form                     */
static int16_t func3 ( );

/* Compliant - prototype specifies 0 parameters              */
static int16_t func4 ( void );

/* Compliant                                                 */
int16_t func1 ( int16_t n )
{
  return n;
}

/* Non-compliant - old style identifier and declaration list */
static int16_t func3 ( vec, n )
int16_t *vec;
int16_t  n;
{
  return vec[ n - 1 ];
}

下面这一组示例说明，除函数声明和定义外，本规则还如何应用于其他地方出现的函数类型。

/* Non-compliant - no prototype                              */
int16_t ( *pf1 ) (  );

/* Compliant - prototype specifies 0 parameters              */
int16_t ( *pf1 ) ( void );

/* Non-compliant - parameter name not specified              */
typedef int16_t ( *pf2_t ) ( int16_t );

/* Compliant                                                 */
typedef int16_t ( *pf3_t ) ( int16_t n );

另见

Rule 8.1、Rule 8.4、Rule 17.3

原书代码注释中译（按出现顺序）： func1 的声明和定义符合；func2 缺少形参名，func3 声明不是原型，其定义使用旧式标识符及声明列表，均不符合。func4 的原型指定零个形参，符合。函数指针的空表不是原型；(void) 是零形参原型。pf2_t 未给形参名；pf3_t 的具名形参符合。
