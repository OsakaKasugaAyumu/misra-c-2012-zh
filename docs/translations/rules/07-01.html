原文译文

8.7　字面量和常量

Rule 7.1　不得使用八进制常量。

[Koenig 9]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

开发者在编写带前导零的常量时，可能期望它们被解释为十进制常量。

注： 本规则不适用于八进制转义序列，因为开头的 \ 字符使它们较不容易被混淆。

例外

严格地说，整数常量零（写作单个数字）是八进制常量，但它是本规则允许的例外。

原书示例

extern uint16_t code[ 10 ];

code[ 1 ] = 109;   /* Compliant     - decimal 109 */
code[ 2 ] = 100;   /* Compliant     - decimal 100 */
code[ 3 ] = 052;   /* Non-Compliant - decimal 42  */
code[ 4 ] = 071;   /* Non-Compliant - decimal 57  */

原书代码注释中译（按出现顺序）　前两项符合，分别为十进制 109 和 100；后两项不符合，其十进制值分别是 42 和 57。
