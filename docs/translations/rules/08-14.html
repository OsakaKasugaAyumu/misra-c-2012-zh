Rule 8.14 · restrict 类型限定符

底本定位 §8.8 · PDF／印刷 83／75

原文译文

Rule 8.14　不得使用 restrict 类型限定符。

C99 [未定义 65、66]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C99

理由

谨慎使用 restrict 类型限定符可以提高编译器所生成代码的效率，也可能改善静态分析。但要使用 restrict，程序员必须确信两个或更多指针所操作的内存区域不重叠。

如果 restrict 使用不当，编译器生成的代码很可能不会按预期工作。

原书示例

下例符合本规则，因为 MISRA C 指南不适用于标准库函数。程序员必须确保 p、q 和 n 所确定的区域不重叠。

#include <string.h>

void f ( void )
{
  /* memcpy has restrict-qualified parameters */
  memcpy ( p, q, n );
}

下例不符合本规则，因为在定义函数时使用了 restrict。

void user_copy ( void * restrict p, void * restrict q, size_t n )
{
}

原书代码注释中译（按出现顺序）： memcpy 的形参带 restrict 限定。
