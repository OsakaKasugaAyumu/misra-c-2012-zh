Rule 20.11 · 逐记号检查井号、形参与双井号的相邻关系

底本定位 PDF／印刷 170／162。

原文译文

Rule 20.11　紧跟在 # 运算符之后的宏形参，其后不得紧接 ## 运算符。

C90 [未指定 12]；C99 [未指定 25]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

对于多个 #、多个 ## 或两者混用的情况，这些预处理运算符的求值次序是未指定的。Rule 20.10 不鼓励使用 # 和 ##。尤其是，# 运算符的结果是一个字符串字面量，把它与其他任何预处理记号拼接，极不可能得到有效记号。

原书示例

#define A( x )      #x         /* Compliant     */
#define B( x, y )   x ## y     /* Compliant     */
#define C( x, y )   #x ## y    /* Non-compliant */

原书代码注释中译（依次）： （1）合规。 （2）合规。 （3）不合规。

另见

Rule 20.10。

源页核对： PDF 170：原书把只含 # 或只含 ## 的两个定义标为合规；此处指 20.11，不撤销 20.10 的建议。
