Rule 18.3 · 按对象归属审查指针的关系比较

底本定位 PDF／印刷 154／146。

原文译文

Rule 18.3　不得对指针类型的对象使用关系运算符 >、>=、<、<=，除非这些指针指向同一个对象之内。

C90 [未定义 33]；C99 [未定义 50]

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

如果两个指针不是指向同一对象，试图在它们之间进行这种比较就会产生未定义行为。

注： 允许取得数组尾后位置的地址，但不允许访问该位置的元素。

原书示例

void f1 ( void )
{
  int32_t  a1[ 10 ];
  int32_t  a2[ 10 ];
  int32_t *p1 = a1;

  if ( p1 < a1 )       /* Compliant     */
  {
  }
  if ( p1 < a2 )       /* Non-compliant */
  {
  }
}

struct limits
{
  int32_t lwb;
  int32_t upb;
};

void f2 ( void )
{
  struct limits limits_1 = { 2, 5 };
  struct limits limits_2 = { 10, 5 };

  if ( &limits_1.lwb <= &limits_1.upb )   /* Compliant     */
  {
  }
  if ( &limits_1.lwb > &limits_2.upb )    /* Non-Compliant */
  {
  }
}
