Rule 5.5 · 标识符与宏名的区分

底本定位 §8.5 · PDF 61／印刷 53

原文译文

Rule 5.5　标识符必须能与宏名区分开。

C90 [未定义 7]，C99 [未指定 7；未定义 28]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本规则要求，预处理前存在的宏名必须能与预处理后存在的标识符区分开。它适用于任何作用域或名字空间中的标识符，也适用于所有曾定义过的宏，不论声明标识符时该宏定义是否仍然有效。

何谓“可区分”，取决于实现以及所使用的 C 语言版本：

  • C90 的最低要求是前 31 个字符有效；
  • C99 的最低要求是前 63 个字符有效，每个通用字符或扩展源字符按一个字符计。

理由

使宏名和标识符彼此可区分，有助于避免开发者产生混淆。

原书示例

在下面这个不符合规则的示例中，函数式宏 Sum 的名字也被用作标识符。对象 Sum 的声明中，该名字后面没有 ( 字符，因此不会发生宏展开。预处理完成后，这个标识符仍然存在。

#define Sum(x, y) ( ( x )  + ( y ) )

int16_t Sum;

下面的示例符合规则，因为预处理后不再出现标识符 Sum。

#define Sum(x, y) ( ( x )  + ( y ) )

int16_t x = Sum ( 1, 2 );

在下面的示例中，对于不具有外部链接的标识符，这里的实现支持 31 个有效字符，区分大小写。该示例不符合规则，因为在前 31 个字符内，宏名与一个具有内部链接的标识符名不可区分。

/*             1234567890123456789012345678901********* Characters */
#define        low_pressure_turbine_temperature_1  lp_tb_temp_1
static int32_t low_pressure_turbine_temperature_2;
