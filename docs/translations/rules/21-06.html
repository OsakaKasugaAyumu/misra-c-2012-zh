Rule 21.6 · 分开审查窄字符与宽字符 I/O

底本定位 PDF／印刷 176–177／168–169。

原文译文

Rule 21.6　不得使用标准库的输入／输出函数。

C90 [未指定 2–5、16–18；未定义 77–89；实现定义 53–68]

C99 [未指定 3–6、34–37；未定义 138–166、186；实现定义 J.3.12(14–32)]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

本条适用于规定由 <stdio.h> 提供的函数；在 C99 中，也适用于 C99 标准第 7.24.2 和 7.24.3 节规定由 <wchar.h> 提供的相应宽字符函数。

不得使用这些标识符中的任何一个，也不得展开与其中任何一个同名的宏。

理由

流和文件 I/O 涉及未指定行为、未定义行为和实现定义的行为。

另见

Rule 22.1、Rule 22.3、Rule 22.4、Rule 22.5、Rule 22.6。
