Rule 2.6 · 未使用的标号

底本定位 §8.2 · PDF 52／印刷 44

原文译文

Rule 2.6　函数中不应含有未使用的标号声明。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

如果一个标号已声明却未使用，审查人员就难以判断该标号是多余的，还是由于疏忽才没有用上。

原书示例

void unused_label ( void )
{
  int16_t x = 6;

label1:              /* Non-compliant */
  use_int16 ( x );
}

原书代码注释中译： 标号 label1 不合规。
