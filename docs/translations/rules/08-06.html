Rule 8.6 · 外部定义的唯一性

底本定位 §8.8 · PDF／印刷 77–78／69–70

原文译文

Rule 8.6　具有外部链接属性的标识符必须恰有一个外部定义。

C90 [未定义 44]，C99 [未定义 78]，[Koenig 55、63–65]

类别
必需（Required）
分析
可判定（Decidable），系统（System）
适用标准
C90、C99

理由

如果一个被使用的标识符有多个定义（在不同文件中），或者根本没有定义，则行为未定义。即使定义相同，本规则也不允许在不同文件中有多个定义。如果声明不同，或者把该标识符初始化为不同的值，则行为未定义。

原书示例

在本例中，对象 i 被定义了两次。

/* file1.c */
int16_t i = 10;

/* file2.c */
int16_t i = 20;   /* Non-compliant - two definitions of i    */

在本例中，对象 j 有一个暂定定义和一个外部定义。

/* file3.c */
int16_t j;        /* Tentative definition                    */
int16_t j = 1;    /* Compliant - external definition         */

下例不符合本规则，因为对象 k 有两个外部定义。file4.c 中的暂定定义在该翻译单元结束时成为外部定义。

/* file4.c */
int16_t k;        /* Tentative definition - becomes external */

/* file5.c */
int16_t k = 0;    /* External definition                     */

原书代码注释中译（按出现顺序）： file1.c 与 file2.c 中有 i 的两个定义，不符合。file3.c 中 j 的暂定定义后面是外部定义，符合。file4.c 中 k 的暂定定义成为外部定义；file5.c 中还有一个外部定义。
