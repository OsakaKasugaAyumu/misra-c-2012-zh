Rule 8.5 · 外部对象或函数的声明来源

底本定位 §8.8 · PDF／印刷 77／69

原文译文

Rule 8.5　外部对象或函数必须只声明一次，并且只能在一个文件中声明。

[Koenig 66]

类别
必需（Required）
分析
可判定（Decidable），系统（System）
适用标准
C90、C99

进一步说明

本规则仅适用于非定义声明。

理由

通常做法是在一个头文件中写一份声明，并在每个定义或使用该标识符的翻译单元中包含这个头文件。这能确保以下两方面的一致性：

  • 声明与定义之间；
  • 不同翻译单元中的各声明之间。

注： 项目中可能有许多头文件，但每个外部对象或函数只能在一个头文件中声明。

原书示例

/* featureX.h */
extern int16_t a;   /* Declare a */

/* file.c */
#include "featureX.h"

int16_t a = 0;      /* Define a  */

另见

Rule 8.4

原书代码注释中译（按出现顺序）： featureX.h 中声明 a；file.c 包含这个头文件并定义 a。
