Rule 18.6 · 追踪被保存的地址和对象生存期

底本定位 PDF／印刷 158／150。

原文译文

Rule 18.6　不得将具有自动存储期的对象的地址，复制到在该对象不再存在之后仍然存续的另一对象中。

C90 [未定义 9、26]；C99 [未定义 8、9、40]

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

对象的地址可以通过下列方式复制：

  • 赋值；
  • 内存移动或复制函数。

理由

对象的生存期一旦结束，其地址就变成不确定值。对不确定地址的任何使用都会导致未定义行为。

原书示例

int8_t *func ( void )
{
  int8_t local_auto;

  return &local_auto;     /* Non-compliant - &local_auto is indeterminate
                           *                 when func returns           */
}

原书代码注释中译（依次）： 不合规：函数返回时，局部对象 local_auto 的地址成为不确定值。

下例中，函数 g 保存了指针形参 p 的一个副本。如果 p 始终指向具有静态存储期的对象，那么就本条而言，代码是合规的。然而，在给出的例子中，p 确实指向具有自动存储期的对象。在这种情况下，复制形参 p 的值就不合规。

uint16_t *sp;

void g ( uint16_t *p )
{
  sp = p;                 /* Non-compliant - address of f's parameter u
                           *                 copied to static sp         */
}

void f ( uint16_t u )
{
  g ( &u );
}

void h ( void )
{
  static uint16_t *q;

  uint16_t x = 0u;

  q = &x;                 /* Non-compliant - &x stored in object with
                           *                 greater lifetime            */
}

原书代码注释中译（依次）： （1）不合规：f 的形参 u 的地址被复制到具有静态存储期的 sp。 （2）不合规：x 的地址被存入生存期更长的对象。
