Rule 2.7 · 未使用的函数形参

底本定位 §8.2 · PDF 52–53／印刷 44–45

原文译文

Rule 2.7　函数中不应有未使用的形参。

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

大多数函数的规格都要求函数使用它的每一个形参。如果某个形参未使用，函数实现就有可能与其规格不符。本规则要指出的就是这类潜在的不一致。

原书示例

void withunusedpara ( uint16_t *para1,
                      int16_t   unusedpara )   /* Non-compliant - unused */
{
  *para1 = 42U;
}

原书代码注释中译： 不合规——没有使用 unusedpara。
