Rule 17.2 · 排查直接与间接递归

底本定位 PDF／印刷 145／137。

原文译文

Rule 17.2　函数不得直接或间接调用自身。

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

理由

递归有耗尽可用栈空间的危险，可能导致严重失效。除非对递归作非常严格的控制，否则无法在执行前确定最坏情况下的栈用量。
