Rule 8.4 · 外部链接对象与函数的声明

底本定位 §8.8 · PDF 75–76 / 印刷 67–68

原文译文

Rule 8.4　在定义具有外部链接属性的对象或函数时，必须有一个与之兼容的声明在该处可见。

C90 [Undefined 24]，C99 [Undefined 39]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

所谓兼容声明，是指该声明为正在定义的对象或函数声明了一个与其类型兼容的类型。

理由

如果在定义对象或函数时，该对象或函数的声明可见，编译器就必须检查该声明与定义是否兼容。如果按 Rule 8.2 的要求提供了函数原型，检查还会涵盖函数参数的数量和类型。

对于具有外部链接属性的对象和函数，推荐的做法是在头文件中声明它们，然后在所有需要这些声明的代码文件中包含该头文件，包括定义这些对象或函数的代码文件（见 Rule 8.5）。

原书示例

在以下示例中，除代码中所列的声明和定义外，不存在其他对象或函数的声明或定义。

extern int16_t count;
       int16_t count = 0;        /* Compliant                            */

extern uint16_t speed = 6000u;   /* Non-compliant - no declaration
                                  * prior to this definition             */
uint8_t pressure = 101u;         /* Non-compliant - no declaration
                                  * prior to this definition             */

extern void func1 ( void );
extern void func2 ( int16_t x, int16_t y );
extern void func3 ( int16_t x, int16_t y );

void func1 ( void )
{
  /* Compliant */
}

原书代码注释中译（按出现顺序）：

  • count 的定义：符合。
  • speed 的定义：不符合——在此定义之前没有声明。
  • pressure 的定义：不符合——在此定义之前没有声明。
  • func1 的定义：符合。

下面 func3 的定义不符合本规则，也违反了 Rule 8.3。

void func2 ( int16_t x, int16_t y )
{
  /* Compliant                                 */
}

void func3 ( int16_t x, uint16_t y )
{
  /* Non-compliant - parameter types different */
}

void func4 ( void )
{
  /* Non-compliant - no declaration of func4 before this definition      */
}

static void func5 ( void )
{
  /* Compliant - rule does not apply to objects/functions with internal
   * linkage                                                             */
}

原书代码注释中译（按出现顺序）：

  • func2：符合。
  • func3：不符合——参数类型不同。
  • func4：不符合——在此定义之前没有 func4 的声明。
  • func5：符合——本规则不适用于具有内部链接属性的对象或函数。
