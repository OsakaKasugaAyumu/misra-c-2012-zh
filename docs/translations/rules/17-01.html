Rule 17.1 · 不用 stdarg.h 的设施

底本定位 PDF／印刷 144–145／136–137。

原文译文

§8.17　函数

Rule 17.1　不得使用 <stdarg.h> 提供的设施。

C90 [未定义 45、70–76]；C99 [未定义 81、128–135]

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

不得使用 va_list、va_arg、va_start、va_end；对 C99，还不得使用 va_copy。

理由

C 标准列出了许多与 <stdarg.h> 设施有关的未定义行为，包括：

  • 在使用过 va_start 的函数结束之前没有使用 va_end；
  • 在不同的函数中对同一个 va_list 使用 va_arg；
  • 某个实参的类型与传给 va_arg 的指定类型不兼容。

原书示例

#include <stdarg.h>

void h ( va_list ap )            /* Non-compliant                   */
{
  double y;

  y = va_arg ( ap, double );     /* Non-compliant                   */
}

void f ( uint16_t n, ... )
{
  uint32_t x;

  va_list  ap;                   /* Non-compliant                     */

  va_start ( ap, n );            /* Non-compliant                     */
  x = va_arg ( ap, uint32_t );   /* Non-compliant                     */

  h ( ap );

  /* undefined - ap is indeterminate because va_arg used in h ( )     */
  x = va_arg ( ap, uint32_t );   /* Non-compliant                     */

  /* undefined - returns without using va_end ( )                     */
}

void g ( void )
{
  /* undefined - uint32_t:double type mismatch when f uses va_arg ( ) */
  f ( 1, 2.0, 3.0 );
}

原书代码注释中译（依次）： （1）不合规。 （2）不合规。 （3）不合规。 （4）不合规。 （5）不合规。 （6）未定义：在 h() 中用过 va_arg，ap 已处于不确定状态。 （7）不合规。 （8）未定义：没有使用 va_end() 就返回。 （9）未定义：f 使用 va_arg() 时，uint32_t 与 double 类型不匹配。
