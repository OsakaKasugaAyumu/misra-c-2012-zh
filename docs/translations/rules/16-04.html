Rule 16.4 · 显式提供 default

底本定位 PDF／印刷 140–141／132–133。

原文译文

Rule 16.4　每条 switch 语句都必须有一个 default 标号。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

default 标号后的 switch 子句必须在收尾的 break 语句之前包含下列两者之一：

  • 一条语句；或
  • 一条注释。

理由

要求提供 default 标号是一种防御式编程。该标号后的语句旨在采取适当的行动。如果标号后没有这样的语句，则可以用注释解释为何不采取具体行动。

原书示例

int16_t x;

switch ( x )
{
  case 0:
    ++x;
    break;
  case 1:
  case 2:
    break;
                     /* Non-compliant - default label is required      */
}

int16_t x;

switch ( x )
{
  case 0:
    ++x;
    break;
  case 1:
  case 2:
    break;
  default:           /* Compliant - default label is present           */
    errorflag = 1;   /* should be non-empty if possible                */
    break;
}

enum Colours
{ RED, GREEN, BLUE } colour;

switch ( colour )
{
  case RED:
    next = GREEN;
    break;
  case GREEN:
    next = BLUE;
    break;
  case BLUE:
    next = RED;
    break;
                     /* Non-compliant - no default label.
                      * Even though all values of the enumeration are
                      * handled there is no guarantee that colour takes
                      * one of those values                            */
}

原书代码注释中译（依次）： （1）不合规：必须有 default 标号。 （2）合规：有 default 标号。 （3）可能的话，不应让这里为空。 （4）不合规：没有 default 标号。虽然已处理枚举的所有枚举值，但不能保证 colour 的取值是其中之一。

另见

Rule 2.1、Rule 16.1。
