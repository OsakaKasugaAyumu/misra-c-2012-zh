Rule 14.2 · for 的三子句与循环体

底本定位 规则 PDF／印刷 126–127／118–119。

原文译文

Rule 14.2　for 循环必须具有规范的结构。

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

for 语句的三个子句如下。

第一子句必须是以下三者之一：

  • 留空；或者
  • 给循环计数器赋值；或者
  • 定义并初始化循环计数器（C99）。

第二子句必须同时满足：

  • 是一个没有持久副作用的表达式；并且
  • 使用循环计数器，还可使用循环控制标志；并且
  • 不使用任何其他在 for 循环体内被修改的对象。

第三子句必须同时满足：

  • 是一个表达式，其唯一的持久副作用是修改循环计数器的值；并且
  • 不使用在 for 循环体内被修改的对象。

一个 for 循环必须只有一个循环计数器，且不得在循环体内修改它。

循环控制标志定义为单个标识符，它指代一个具有本质布尔类型、且在第二子句中使用的对象。

for 循环体的行为包括该语句内调用的任何函数的行为。

理由

for 语句提供通用的循环机制。限制 for 循环的形式，可以使代码更容易审查和分析。

例外

为了允许无限循环，三个子句可以全部留空，例如 for ( ; ; )。

原书示例

在下面这个 C99 示例中，i 是循环计数器，flag 是循环控制标志。

bool_t flag = false;

for ( int16_t i = 0; ( i < 5 ) && !flag; i++ )
{
  if ( C )
  {
    flag = true;                /* Compliant - allows early termination
                                 * of loop                               */
  }

  i = i + 3;                    /* Non-compliant - altering the loop
                                 * counter                               */
}

另见

Rule 14.1、Rule 14.3、Rule 14.4。

原书代码注释中译（按出现顺序）： 设置 flag 符合，因为它允许循环提前终止。在循环体内给 i 加 3 不符合，因为这改变了循环计数器。
