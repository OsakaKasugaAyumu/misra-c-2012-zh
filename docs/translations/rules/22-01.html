Rule 22.1 · 逐个归还成功取得的资源

底本定位 PDF／印刷 180–181／172–173。

原文译文

8.22　资源

本节的许多规则，只有在其他节的规则已有偏离时才适用。

Rule 22.1　通过标准库函数动态取得的所有资源都必须显式释放。

类别
必需（Required）
分析
不可判定（Undecidable），系统（System）
适用标准
C90、C99

进一步说明

分配资源的标准库函数是 malloc、calloc、realloc 和 fopen。

理由

如果不显式释放资源，资源耗尽时就有可能发生故障。尽早释放资源，可降低资源耗尽的可能性。

原书示例

#include <stdlib.h>

int main ( void )
{
  void *b = malloc ( 40 );

  /* Non-compliant - dynamic memory not released */
  return 1;
}

#include <stdio.h>

int main ( void )
{
  FILE *fp = fopen ( "tmp", "r" );

  /* Non-compliant - file not closed             */
  return 1;
}

原书代码注释中译（依次）： （1）不合规：未释放动态内存。 （2）不合规：文件未关闭。

在下面的不合规示例中，打开 "tmp-2" 时，失去了指向 "tmp-1" 的句柄。

#include <stdio.h>

int main ( void )
{
  FILE *fp;

  fp = fopen ( "tmp-1", "w" );

  fprintf ( fp, "*" );

  /* File "tmp-1" should be closed here, but stream 'leaks'. */

  fp = fopen ( "tmp-2", "w" );

  fprintf ( fp, "!" );

  fclose ( fp );

  return ( 0 );
}

原书代码注释中译（依次）： （1）本应在这里关闭文件 tmp-1，但这个流“泄漏”了。
