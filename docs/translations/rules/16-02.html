Rule 16.2 · 把 switch 标号放在语句体最外层

底本定位 PDF／印刷 139／131。

原文译文

Rule 16.2　只有当最近一层包围它的复合语句就是 switch 语句体时，才允许使用 switch 标号。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

C 标准允许把 switch 标号（即 case 或 default 标号）放在 switch 语句体内的任何语句之前。这可能造成代码缺乏结构。为避免这种情况，switch 标号只能出现在构成 switch 语句体的复合语句的最外层。

原书示例

switch ( x )
{
  case 1:         /* Compliant     */
    if ( flag )
    {
  case 2:         /* Non-compliant */
      x = 1;
    }
    break;
  default:
    break;
}

原书代码注释中译（依次）： （1）合规。 （2）不合规。
