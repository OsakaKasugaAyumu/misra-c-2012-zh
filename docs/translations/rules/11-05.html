Rule 11.5 · 从 void 指针到对象指针

底本定位 规则 PDF／印刷 106／98。

原文译文

Rule 11.5　不应将指向 void 的指针转换为指向对象的指针。

C90 [未定义 20]；C99 [未定义 22、34]

类别
建议（Advisory）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

理由

将指向 void 的指针转换为指向对象的指针，可能产生未正确对齐的指针，导致未定义行为。应尽可能避免这种转换，但有时可能不可或缺，例如使用内存分配函数时。如果使用了从指向对象的指针到指向 void 的指针的转换，就应注意确保所得指针不会引发 Rule 11.3 讨论的未定义行为。

例外

类型为“指向 void 的指针”的空指针常量可转换为指向对象的指针。

原书示例

uint32_t *p32;
void     *p;
uint16_t *p16;

p   = p32;                /* Compliant - pointer to uint32_t into
                           * pointer to void                             */
p16 = p;                  /* Non-compliant                               */
p   = ( void * ) p16;     /* Compliant                                   */
p32 = ( uint32_t * ) p;   /* Non-compliant                               */

另见

Rule 11.2、Rule 11.3。

原书代码注释中译（按出现顺序）： p32 到 p 符合（指向 uint32_t 的指针到指向 void 的指针）；p 到 p16 不符合；p16 到 p 符合；p 到 p32 不符合。

源页核对： PDF 106：规则标题及理由首句是 void 指针 → 对象指针，理由末句却写对象指针 → void 指针。分别照底本翻译，末句不改写为与标题同向。
