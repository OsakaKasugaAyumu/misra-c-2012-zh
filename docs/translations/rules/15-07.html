Rule 15.7 · 为 else if 链写收尾 else

底本定位 PDF／印刷 137／129。

原文译文

Rule 15.7　所有 if … else if 结构都必须以 else 语句结束。

类别
必需（Required）
分析
可判定（Decidable），单一翻译单元（Single Translation Unit）
适用标准
C90、C99

进一步说明

只要 if 之后有一个或多个 else if，就必须提供最后的 else。这个 else 必须至少包含一个副作用或一条注释。

理由

以 else 结束一串 if … else if 是防御式编程，与 switch 必须有 default 子句的要求相辅相成（见 Rule 16.5）。

要求 else 具有副作用或含有注释，是为了让代码明确表明期望的行为，便于审查。

注： 单独一个简单的 if 不要求带有最后的 else。

原书示例

下例不合规，因为它没有通过收尾的 else 明确表示无需采取任何动作。

if ( flag_1 )
{
  action_1 ( );
}
else if ( flag_2 )
{
  action_2 ( );
}

/* Non-compliant */

原书代码注释中译（依次）： 不合规。

下面给出了合规的收尾 else。

else
{
  ;   /* No action required - ; is optional */
}

原书代码注释中译（依次）： 无需采取行动；分号是可选的。

另见

Rule 16.5。

源页核对： PDF 137：理由与“另见”均指向 Rule 16.5，译文保留两处引用。就本批而言，要求设置 default 的是 Rule 16.4；Rule 16.5 规定它放在何处。
