Dir 4.4 · 不应用注释停用代码

底本定位 §7.4 · PDF 35／印刷 27，止于 Dir 4.5 标题前。

原文译文

Dir 4.4　不应把成段代码“注释掉”。

类别
建议（Advisory）
适用标准
C90、C99

进一步说明

本规则既适用于 // 形式的注释，也适用于 /* ... */ 形式的注释。

理由

需要让某些源代码段不参与编译时，应当使用条件编译来实现（例如，采用 #if 或 #ifdef 结构，并附上注释）。用注释的起止标记来达到这个目的是危险的：C 不支持嵌套注释，代码段中原本就有的注释会改变这样做的效果。

另见

Rule 3.1、Rule 3.2。
