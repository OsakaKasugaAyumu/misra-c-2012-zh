Dir 4.9 · 可以互换时优先使用函数

底本定位 §7.4 · PDF 39–40／印刷 31–32，止于 Dir 4.10 标题前。

原文译文

Dir 4.9　在函数与函数式宏可以互换的场合，应优先使用函数。

[Koenig 78–81]

类别
建议（Advisory）
适用标准
C90、C99

进一步说明

本准则仅适用于语言标准的语法和约束允许使用函数的场合。

理由

在大多数情况下，应使用函数而不是宏。函数会对实参进行类型检查，并且每个实参只求值一次，从而避免了副作用可能多次发生所带来的问题。在许多调试系统中，单步跟踪函数的执行比单步跟踪宏的执行更容易。不过，在某些场合，宏仍然有用。

决定使用函数还是宏时，应考虑的因素包括：

  • 对函数实参和返回结果进行类型检查的好处；
  • C99 提供了内联函数，但要注意，实现会在多大程度上采纳 inline，是实现定义的；
  • 代码大小与执行速度之间的取舍；
  • 对当前用途而言，编译时求值的可能性是否重要：实参为常量的宏比相应的函数调用更有可能在编译时求值；
  • 这些实参对函数而言是否合法：宏的实参是文本，而函数的实参是表达式；
  • 是否易于理解和维护。

原书示例

下例合规。这里的函数式宏以一个 C 运算符作为实参，因此不能用函数替换：

#define EVAL_BINOP( OP, L, R ) ( ( L ) OP ( R ) )

uint32_t  x = EVAL_BINOP ( +, 1, 2 );

下例中，用宏初始化具有静态存储期的对象是合规的，因为此处不允许函数调用。

#define DIV2(X) ( ( X ) / 2 )

void f ( void )
{
  static uint16_t x = DIV2 ( 10 );   /* Compliant - call not permitted */
         uint16_t y = DIV2 ( 10 );   /* Non-compliant - call permitted */
}

原书代码注释（译）：x 所在行：“合规——此处不允许调用函数”；y 所在行：“不合规——此处允许调用函数”。
