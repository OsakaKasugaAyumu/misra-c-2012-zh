Dir 4.12 · 不得使用动态内存分配

底本定位 §7.4 · PDF 42–43／印刷 34–35，止于 Dir 4.13 标题前。

原文译文

Dir 4.12　不得使用动态内存分配。

类别
必需（Required）
适用标准
C90、C99

进一步说明

本规则适用于所有动态内存分配软件包，包括：

  • 标准库提供的软件包；
  • 第三方软件包。

理由

如 Rule 21.3 所述，标准库中动态分配和释放内存的例程可能导致未定义行为。其他动态内存分配系统也很可能表现出与标准库类似的未定义行为。

必须核查第三方例程的规格说明，确保没有在不知情的情况下使用动态内存分配。

如果决定使用动态内存，就必须谨慎处理，确保软件以可预测的方式运行。例如，存在下列风险：

  • 可用内存可能不足以满足请求——必须确保分配失败时，软件能作出安全、适当的响应；
  • 分配或释放内存所需的执行时间可能波动很大，这取决于内存的使用模式以及由此产生的碎片化程度。

原书示例

为便于说明，这些例子采用标准库的动态内存函数，因为这些函数的接口为人熟知。

在本例中，第一次调用 free 之后，指针 p 的值变为不确定值，因此随后的行为是未定义的。虽然调用 free 后指针中存储的值没有改变，但在某些目标平台上，它指向的内存可能已经不存在；仅仅复制该指针，就可能引发内存异常。

#include <stdlib.h>

void f ( void )
{
  char     *p = ( char * ) malloc ( 10 );
  char     *q;

  free ( p );
  q = p;         /* Undefined behaviour - value of p is indeterminate    */


  p = ( char * ) malloc ( 20 );
  free ( p );
  p = NULL;      /* Assigning NULL to freed pointer makes it determinate */
}

原书代码注释（译）：q = p; 一行是“未定义行为——p 的值不确定”；p = NULL; 一行是“给已释放内存所对应的指针赋 NULL，使其具有确定值”。
