7.2　编译与构建

Dir 2.1　所有源文件都必须在没有任何编译错误的情况下完成编译。

类别
必需（Required）
适用标准
C90、C99

理由

即使存在编译错误，符合标准的编译器仍可以生成目标模块。然而，执行由此得到的程序可能产生非预期行为。

关于如何控制和分析编译器消息，更多指导见 §5.3.1。

Rule 1.1。
