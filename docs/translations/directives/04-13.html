Dir 4.13 · 按适当顺序调用资源操作函数

底本定位 §7.4 · PDF 43–44／印刷 35–36，从 Dir 4.13 标题起，止于第 45 页 §8 标题前。

原文译文

Dir 4.13　为操作某一资源而设计的函数，应按适当的顺序调用。

类别
建议（Advisory）
适用标准
C90、C99

进一步说明

一组用于操作某一资源的函数，通常提供三类操作：

  1. 分配资源，例如打开文件；
  2. 释放资源，例如关闭文件；
  3. 其他操作，例如读取文件。

对于每一组这样的函数，只要用到其中的操作，就应遵循适当的调用顺序。

理由

静态分析工具可以进行路径分析检查，找出程序中哪些执行路径没有调用操作序列中的资源释放函数。因此，为了充分利用这类自动检查，鼓励开发者设计成组配对的函数，并向静态分析工具声明它们的配对关系，以便工具进行这些检查。

原书示例

/* These functions are intended to be paired */
extern mutex_t mutex_lock   ( void );
extern void    mutex_unlock ( mutex_t m );

extern int16_t x;

void f ( void )
{
  mutex_t m = mutex_lock ( );

  if ( x > 0 )
  {
    mutex_unlock ( m );
  }
  else
  {
    /* Mutex not unlocked on this path */
  }
}

原书代码注释（译）：声明前的注释是“这些函数应配对使用”；else 分支中的注释是“在这条路径上没有解锁互斥锁”。
