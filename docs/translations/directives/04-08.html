Dir 4.8 · 不解引用指针时隐藏对象的实现

底本定位 §7.4 · PDF 38–39／印刷 30–31，止于 Dir 4.9 标题前。

原文译文

Dir 4.8　如果在某个翻译单元中从不对指向结构体或联合体的指针解引用，就应隐藏该对象的实现。

类别
建议（Advisory）
适用标准
C90、C99

进一步说明

应通过指向不完整类型的指针来隐藏对象的实现。

理由

如果从不对指向结构体或联合体的指针解引用，就不需要知道该对象的实现细节；应当保护对象的内容，使其不会被无意改动。

隐藏实现细节会形成一种不透明类型：可以通过指针引用这种类型的对象，但不能访问其内容。

原书示例

/* Opaque.h */

#ifndef OPAQUE_H
#define OPAQUE_H

typedef struct OpaqueType *pOpaqueType;

#endif

/* Opaque.c */

#include "Opaque.h"

struct OpaqueType
{
  /* Object implementation */
};

/* UseOpaque.c */

#include "Opaque.h"

void f ( void )
{
  pOpaqueType pObject;

  pObject = GetObject ( );   /* Get a handle to an OpaqueType object */

  UseObject ( pObject );     /* Use it...                            */
}

原书代码注释（译）：三个文件标记依次为“Opaque.h”“Opaque.c”“UseOpaque.c”。结构体内的注释为“对象的实现”；调用处的两条注释依次为“取得一个指向 OpaqueType 对象的句柄”和“使用它……”。
