Dir 4.5 · 避免字形容易混淆的标识符

底本定位 §7.4 · PDF 35–36／印刷 27–28，自 Dir 4.5 标题起。

原文译文

Dir 4.5　在同一名字空间中，可见范围有重叠的标识符应当能从字形上明确区分。

类别
建议（Advisory）
适用标准
C90、C99

进一步说明

项目应当根据编写源代码所用的字母表和语言，确定“能明确区分”的具体含义。

对于英语单词所用的拉丁字母，建议至少做到：两个标识符之间的差别不应仅仅是下列变化中的任意组合：

  • 小写字母与对应的大写字母互换；
  • 有无下划线字符；
  • 字母 O 与数字 0 互换；
  • 字母 I 与数字 1 互换；
  • 字母 I 与字母 l（小写 L）互换；
  • 字母 l（小写 L）与数字 1 互换；
  • 字母 S 与数字 5 互换；
  • 字母 Z 与数字 2 互换；
  • 字母 n 与字母 h 互换；
  • 字母 B 与数字 8 互换；
  • 字母序列 rn（r 后跟 n）与字母 m 互换。

理由

根据显示字符集所用的字体不同，某些字符即使不同，其字形也可能看上去相同。这可能使开发者把一个标识符误认为另一个。

原书示例

以下示例假定，对于拉丁字母表和英语，采用的是“进一步说明”中建议的判别方式。

int32_t   id1_a_b_c;
int32_t   id1_abc;     /* Non-compliant */

int32_t   id2_abc;
int32_t   id2_ABC;     /* Non-compliant */

int32_t   id3_a_bc;
int32_t   id3_ab_c;    /* Non-compliant */

int32_t   id4_I;
int32_t   id4_1;       /* Non-compliant */

int32_t   id5_Z;
int32_t   id5_2;       /* Non-compliant */

int32_t   id6_O;
int32_t   id6_0;       /* Non-compliant */

int32_t   id7_B;
int32_t   id7_8;       /* Non-compliant */

int32_t   id8_rn;
int32_t   id8_m;       /* Non-compliant */

int32_t   id9_rn;
struct
{
  int32_t id9_m;       /* Compliant     */
};

原书代码注释（译）：id1_abc、id2_ABC、id3_ab_c、id4_1、id5_2、id6_0、id7_8 和 id8_m 所在行均标为“不合规”；结构体成员 id9_m 所在行标为“合规”。
