Dir 4.2 · 记录汇编语言的使用

底本定位 §7.4 · PDF 34／印刷 26；止于本页下一条指令之前。

原文译文

Dir 4.2　凡使用汇编语言之处，都应记录在文档中。

类别
建议（Advisory）
适用标准
C90、C99

进一步说明

应当记录使用汇编语言的理由，以及 C 与汇编语言之间的接口机制。

理由

汇编语言代码由实现定义，因此不可移植。
