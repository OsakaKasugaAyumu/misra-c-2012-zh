Dir 4.1 · 尽可能减少运行时失效

底本定位 §7.4 · PDF 32–33／印刷 24–25。

原文译文

7.4　代码设计

Dir 4.1　必须尽可能减少运行时失效。

C90 [Undefined 15, 19, 26, 30, 31, 32, 94]
C99 [Undefined 15, 16, 33, 40, 43–45, 48, 49, 113]

类别
必需（Required）
适用标准
C90、C99

理由

C 语言在设计上只提供很有限的内建运行时检查。这种做法使生成的可执行代码可以既紧凑又快速，但也把运行时检查的责任交给了程序员。因此，要达到预期的健壮性水平，程序员就应当对每一处可能发生运行时错误的地方，认真考虑是否添加动态检查。

有时可以证明，操作数的取值排除了表达式求值期间发生运行时错误的可能。在这种情况下，只要把省略检查的论证记录下来，就不需要动态检查。这份记录应当包括论证所依赖的假设。以后修改代码时，可以利用这些信息确认原有论证仍然成立。

对于将用来尽可能减少运行时失效的技术，应当事先规划并记录下来，例如写入设计标准、测试计划、静态分析配置文件和代码审查清单。具体采用什么技术，可能取决于项目的完整性要求。详见§5.2。

注： 出现运行时错误，表明违反了 Rule 1.3。

以下说明给出一些指导，指出在哪些方面需要考虑设置动态检查。

  • 算术错误　这包括表达式求值期间发生的错误，例如上溢、下溢、除以零，或因移位而丢失有效位。考虑整数上溢时须注意：严格来说，无符号整数运算不会上溢，而是发生回绕；所得的值有定义，但可能并非预期值。应当仔细考虑算术表达式中各值的范围以及运算的先后顺序。例如：

    float32_t f1 = 1E38f;
float32_t f2 = 10.0f;
float32_t f3 = 0.1f;
float32_t f4 = ( f1 * f2 ) * f3;   /* (f1 * f2) will overflow        */
float32_t f5 = f1 * ( f2 * f3 );   /* no overflow because (f2 * f3)
                                    * is (approximately) 1           */

if ( ( f3 >= 0.0f ) && ( f3 <= 1.0f ) )
{
  /*
   * no overflow because f3 is known to be in range 0..1 so the
   * result of the multiplication will fit in type float32_t
   */
  f4 = f3 * 100.0f;
}

    原书代码注释（译）：① f1 * f2 会上溢。② 不会上溢，因为 f2 * f3（近似）为 1。③ 不会上溢，因为已知 f3 在 0 到 1 的范围内，乘积可以用 float32_t 表示。

  • 指针运算　动态计算地址时，要确保算出的地址合理，指向有意义的位置。尤其要确保：如果指针原来指向某个数组内，那么对它作递增或其他改动之后，它仍指向同一个数组内。指针运算的限制见 Rule 18.1、Rule 18.2 和 Rule 18.3。

  • 数组边界错误　在用下标访问数组之前，要确保下标在该数组大小所限定的范围内——见 Rule 18.1。

  • 函数参数　在把实参传给库函数之前，应当检查这些实参是否有效——见 Dir 4.11。

  • 指针解引用　除非已知某个指针不是 NULL，否则在对它解引用之前，应当进行运行时检查。作过一次检查之后，在同一个函数内，要推断指针是否可能已经改变、因而是否需要再次检查，相对比较容易。跨越函数边界时，这种推断就困难得多，尤其是在调用其他源文件或库中定义的函数时。

    /*
 * Given a pointer to a message, check the message header and return
 * a pointer to the body of the message or NULL if the message is
 * invalid.
 */
const char *msg_body ( const char *msg )
{
  const char *body = NULL;

  if ( msg != NULL )
  {
    if ( msg_header_valid ( msg ) )
    {
      body = &msg[ MSG_HEADER_SIZE ];
    }
  }
  return body;
}

      char  msg_buffer[ MAX_MSG_SIZE ];
const char *payload;

payload = msg_body ( msg_buffer );

/* Check if there is a payload */
if ( payload != NULL )
{
  /* Process the payload */
}

    原书代码注释（译）：① 给定一个指向消息的指针，检查消息头并返回一个指向消息正文的指针；如果消息无效，则返回 NULL。② 检查是否有有效载荷。③ 处理有效载荷。

  • 动态内存　如果进行动态内存分配，务必检查每一次分配是否成功，并设计和测试适当的降级或恢复策略。
