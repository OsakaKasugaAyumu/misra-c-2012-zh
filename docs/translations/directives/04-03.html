Dir 4.3 · 封装并隔离汇编语言

底本定位 §7.4 · PDF 34／印刷 26，自 Dir 4.3 标题起。

原文译文

Dir 4.3　必须对汇编语言进行封装和隔离。

类别
必需（Required）
适用标准
C90、C99

进一步说明

凡使用汇编语言指令，都必须将其封装并隔离在下列形式之一中：

  • 汇编语言函数；
  • C 函数（C99 中优先选用内联函数）；
  • C 宏。

理由

出于效率考虑，有时需要把简单的汇编指令直接嵌入代码，例如用于启用和禁用中断。如果确有这种需要，建议用宏来实现，或在 C99 中用内联函数来实现。

封装汇编语言有以下好处：

  • 提高可读性；
  • 通过封装它的宏或函数的名称和文档，可以清楚表明这段汇编的意图；
  • 凡为同一目的使用汇编语言的地方，都可以共用同一层封装，从而提高可维护性；
  • 换用其他目标平台时，或为了进行静态分析，都可以方便地替换这段汇编代码。

注： 使用内联汇编属于对标准 C 的扩展，因此违反 Rule 1.2。

原书示例

#define NOP asm("    NOP")
