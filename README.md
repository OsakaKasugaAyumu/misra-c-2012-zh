# MISRA C:2012 关联的 C 语言实验笔记

## 在线阅读

[📖 在线浏览原创学习版](https://osakakasugaayumu.github.io/misra-c-2012-zh/)

这里不是标准的在线译本，而是用 C 代码做的 31 个小实验。以准则编号、中文关键词或源码文件名检索，也可以从目录逐个阅读。无需登录。

- **内容**：16 个 Directive 关联实验、15 个 Rule 关联实验，50 份自编 `.c` / `.h` 源码。
- **复现**：在实验页下载同组源码并保持相对目录结构，切换到该实验目录，按页面的 GCC 命令顺序执行。汇编对照面向 x86-64 GCC。每页给出当次构建模式、退出码、标准输出（如有）和诊断要点。
- **证据**：有些对照应当被编译器拒绝，有些应当在运行时返回 1；它们不是站点测试失败。证据边界在每页单独列出。
- **范围**：个人原创、非官方；不包含标准正文、译文、原书示例或 PDF，不代替正式标准或合规审查。

网站为静态 HTML。`docs/` 是唯一的 Pages 发布目录；不依赖外部字体、脚本服务或分析服务。
